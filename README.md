# CSU- 中南大学学习资料

本仓库收集了**中南大学**本科阶段各类课程的学习资料，包括课件、试卷、习题等资源，供同学们参考学习。

## 目录结构

```
├── 大学物理/          # 大学物理课程资料（含历年试卷、实验报告、模拟卷等）
├── 高等数学/          # 高等数学资料（含历年真题、习题等）
├── 线性代数/          # 线性代数资料（含教材、历年试卷、模拟卷）
├── 概率统计/          # 概率论与数理统计
├── 离散数学/          # 离散数学
├── 复变函数/          # 复变函数
├── 思想政治/          # 政治理论课（史纲、马原、党课）
├── 专业课程/          # 专业课程（模电数电、信号与系统、人工智能导论、SQL、电路等）
├── 软件工具/          # 软件工具（Multisim、电子制作AD等）
└── 其他/              # 其他资料
```

## 课程列表

| 类别 | 内容 |
|------|------|
| 大学物理 | 大物上/下册、历年试卷、实验报告、模拟卷、真题卷 |
| 高等数学 | 高数A下真题、题库、试卷 |
| 线性代数 | 教材、历年试卷、模拟卷 |
| 概率统计 | 概率论与数理统计资料 |
| 离散数学 | 离散数学资料 |
| 复变函数 | 复变函数资料 |
| 思想政治 | 中国近现代史纲要、马克思主义基本原理、党课 |
| 专业课程 | 模拟电子/数字电子技术、信号与系统、人工智能导论、SQL、电路、数字逻辑 |
| 软件工具 | Multisim 14.3、电子制作AD |
