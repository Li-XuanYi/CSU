## 一、选择题（3.5' × 3 = 10.5'）

**1.（Matroid Definition & Examples, Slide07）** 下列哪个集合系统 $(S, C)$ **不是**一个拟阵（Matroid）？

- (A) **Matric Matroid**：$S$ 为矩阵 $M$ 的行向量集合，$C$ 为所有线性无关子集
- (B) **Graphic Matroid** $M_G$：$S = E$ 为无向图 $G = (V, E)$ 的边集，$C$ 为所有无环边集（森林）
- (C) **Independent Vertex Set System**：$S = V$ 为无向图 $G = (V, E)$ 的顶点集，$C$ 为所有独立顶点集（任意两顶点不相邻）
- (D) **Uniform Matroid** $U_{k,n}$：$S = \{1, 2, \dots, n\}$，$C = \{X \subseteq S \mid |X| \le k\}$

**答案**：C **解析**：

本题要求选出**不是**拟阵的选项。拟阵须满足两个性质：遗传性（hereditary）和交换性质（exchange property）。逐一分析：

**选项 (A) Matric Matroid — 是拟阵**。矩阵拟阵以矩阵 $M$ 的行向量集合为 $S$，线性无关子集为 $C$。

- **遗传性**：若 $B$ 是线性无关的行向量集合，则 $B$ 的任何子集 $A \subset B$ 也必然线性无关（线性无关组的子集仍线性无关），故 $A \in C$。✓
- **交换性质**：设 $A, B$ 为两个线性无关的行向量组，$|A| < |B|$。则 $\dim(\text{span}(A)) < \dim(\text{span}(B))$。因此 $B$ 中至少存在一个行向量 $x \notin \text{span}(A)$。将该 $x$ 加入 $A$ 后，$A \cup \{x\}$ 仍是线性无关的（因为 $x$ 不在 $A$ 的张成空间中）。✓

**选项 (B) Graphic Matroid — 是拟阵**。图拟阵以无向图 $G=(V,E)$ 的边集 $E$ 为 $S$，无环边集（森林）为 $C$。

- **遗传性**：若 $B$ 是无环边集，则其任何子集 $A \subset B$ 也不含环（去掉边不可能产生新环），故 $A \in C$。✓
- **交换性质**：设 $A, B$ 为两个无环边集，$|A| < |B|$。记 $(V, A)$ 有 $|V| - |A|$ 个连通分量，$(V, B)$ 有 $|V| - |B|$ 个连通分量。由于 $|A| < |B|$，有 $|V| - |A| > |V| - |B|$，即 $(V, A)$ 的连通分量比 $(V, B)$ 多。因此 $B$ 中必存在一条边 $e$，其两个端点位于 $(V, A)$ 的两个不同连通分量中（否则 $B$ 的边不会减少连通分量数，与连通分量数更少矛盾）。将 $e$ 加入 $A$ 不会形成环（因为 $e$ 连接了两个不同分量），故 $A \cup \{e\} \in C$。✓

**选项 (C) Independent Vertex Set System — 不是拟阵**。

- **遗传性**：若 $B$ 是独立顶点集（任意两点不相邻），其子集 $A \subset B$ 显然也是独立顶点集。✓
- **交换性质**：**不满足**。反例：路径 $a-b-c$（边为 $(a,b),(b,c)$）。取 $A = \{a\}$，$B = \{b, c\}$。$|A| = 1 < 2 = |B|$，但 $B \setminus A = \{b, c\}$ 中：
  - 加入 $b$：$A \cup \{b\} = \{a, b\}$，$a$ 与 $b$ 相邻，不是独立顶点集 ✗
  - 加入 $c$：$A \cup \{c\} = \{a, c\}$，$a$ 与 $c$ 不相邻，是独立顶点集 ✓
  
  等一下——$\{a, c\}$ 是独立集，说明交换性质似乎成立了？问题在于这里构造的反例有误。实际上对于独立顶点集系统，我们需要更严格的分析。

  考虑三角形 $K_3$，顶点 $a,b,c$ 两两相连。取 $A = \{a\}$，$B = \{b, c\}$。$|A| = 1 < 2 = |B|$，$B \setminus A = \{b, c\}$。但 $A \cup \{b\} = \{a,b\}$ 不是独立集（$a,b$ 相邻），$A \cup \{c\} = \{a,c\}$ 也不是独立集（$a,c$ 相邻）。因此不存在 $x \in B \setminus A$ 使得 $A \cup \{x\}$ 独立，交换性质不成立。✗

  更一般的论证：独立顶点集系统不是拟阵，因为最大独立集（最大独立集）和极大独立集（任意再加一个顶点就破坏独立性的集）的大小可以不同。例如星形图 $K_{1,3}$ 中，极大独立集可以是 $\{\text{中心}\}$（大小 1）或 $\{3\text{个叶子}\}$（大小 3），大小不等。由拟阵定理（$u(F) = v(F)$ 对所有 $F$ 成立 $\iff$ 是拟阵），取 $F$ 为全体顶点，$u(F)=1 \neq 3=v(F)$，故不是拟阵。

**选项 (D) Uniform Matroid — 是拟阵**。均匀拟阵 $U_{k,n}$ 中 $S = \{1,\dots,n\}$，$C = \{X \subseteq S \mid |X| \le k\}$。

- **遗传性**：若 $|B| \le k$，则 $B$ 的任何子集 $A$ 满足 $|A| \le |B| \le k$，故 $A \in C$。✓
- **交换性质**：设 $A, B$ 满足 $|A| < |B| \le k$。从 $B \setminus A$ 中任取一个元素 $x$（因为 $|B| > |A|$，$B \setminus A$ 非空）。则 $|A \cup \{x\}| = |A| + 1 \le |B| \le k$，故 $A \cup \{x\} \in C$。✓

**结论**：A、B、D 都满足遗传性和交换性质，是拟阵。C 仅满足遗传性但不满足交换性质，不是拟阵。

**2.（u(F) & v(F) & Matroid Theorem, Slide07）** 给定独立系统 $(S, C)$，对任意子集 $F \subseteq S$，定义：

$$u(F) = \min\{|I| \mid I \text{ 是 } F \text{ 的极大独立子集}\}$$
$$v(F) = \max\{|I| \mid I \text{ 是 } F \text{ 的独立子集}\}$$

已知独立系统 $(S, C)$ 中，存在子集 $F \subseteq S$ 使得 $u(F) = 2$，$v(F) = 4$。根据拟阵定理，以下哪个结论是**正确**的？

- (A) $(S, C)$ 一定是拟阵，因为 $u(F) > 0$
- (B) $(S, C)$ 一定不是拟阵，因为 $u(F) \neq v(F)$
- (C) $(S, C)$ 可能是拟阵也可能不是，需要更多信息判断
- (D) $(S, C)$ 一定是拟阵，因为 $u(F) \le v(F)$ 成立

**答案**：B **解析**：拟阵定理指出：独立系统 $(S, C)$ 是拟阵 $\iff$ 对任意 $F \subseteq S$，$u(F) = v(F)$。这里存在某个 $F$ 使得 $u(F) = 2 \neq 4 = v(F)$，因此 $(S, C)$ 一定不是拟阵。注意 $u(F) \neq v(F)$ 意味着 $F$ 中有两个极大独立子集大小不同，这直接违反拟阵中"所有极大独立子集大小相等"的推论。

**3.（Greedy-MAX & Matroid Equivalence, Slide07）** 关于拟阵与 Greedy-MAX 算法，下列哪项表述是**错误**的？

- (A) 若 $(S, C)$ 是拟阵，则对任意代价函数 $c(\cdot)$，Greedy-MAX 算法都能找到最大权独立子集（最优解）
- (B) 在图拟阵 $M_G$ 上运行 Greedy-MAX 求解最小生成树时，等价于 Kruskal 算法
- (C) 在均匀拟阵 $U_{k,n}$ 上运行 Greedy-MAX 算法，等价于选择权值最大的 $k$ 个元素
- (D) Greedy-MAX 算法在任何独立系统上都能保证得到最优解，但拟阵能给出更好的性能比上界

**答案**：D **解析**：A 正确，这是拟阵与 Greedy-MAX 等价定理的正向部分。B 正确，将 MST 的最小化问题转化为最大化问题（令 $c^*(e) = c_{\max} - c(e)$），在图拟阵上运行 Greedy-MAX 等价于 Kruskal 算法。C 正确，均匀拟阵 $U_{k,n}$ 的独立集要求 $|X| \le k$，Greedy-MAX 按权值降序选择前 $k$ 个元素即为最优。D 错误，Greedy-MAX 在一般独立系统上不能保证最优解，贪心定理只给出性能比 $\frac{c(A^*)}{c(A_G)} \le \max_{F \subseteq S} \frac{v(F)}{u(F)}$，只有当 $(S, C)$ 是拟阵（即对所有 $F$ 有 $u(F) = v(F)$）时才能保证最优解。

## 二、问答题（15'）

### 1. 拟阵与单位时间任务调度问题（Matroid & Unit-Time Task Scheduling, Slide07）（15'）

单位时间任务调度问题描述如下：给定 $n$ 个任务 $S = \{1, 2, \dots, n\}$，每个任务 $i$ 需要 1 个单位时间完成，有截止时间 $d_i$（$1 \le d_i \le n$）和惩罚 $w_i$（非负整数）。若任务未在截止时间前完成，则需支付相应惩罚。目标是最小化总惩罚。

一个任务集 $A \subseteq S$ 称为**独立集**，如果存在一个调度方案使得 $A$ 中所有任务都在截止时间前完成。记 $C$ 为所有独立任务集的集合。已知 $(S, C)$ 是一个拟阵（Matroid）。

#### （1）独立性的判定条件（Independence Criterion, Slide07）（3'）

对于任意任务集 $A \subseteq S$，定义 $N_t(A)$ 为 $A$ 中截止时间 $\le t$ 的任务数量。请写出判定 $A$ 是独立集的一个充要条件，并简要解释其含义。

**答案**：

$$A \text{ 是独立集} \iff \forall t = 1, 2, \dots, n,\; N_t(A) \le t$$

**解释**：截止时间 $\le t$ 的任务最多只能有 $t$ 个，因为前 $t$ 个单位时间内最多只能完成 $t$ 个任务。若存在某个 $t$ 使得 $N_t(A) > t$，则意味着有超过 $t$ 个任务需要在 $t$ 时刻前完成，这不可能实现。

等价地，若将 $A$ 中任务按截止时间单调递增顺序调度，则没有任务会延迟。

#### （2）Greedy-MAX 算法设计（Greedy-MAX Design, Slide07）（6'）

基于 $(S, C)$ 是拟阵的性质，设计 Greedy-MAX 算法求解该任务调度问题（最小化总惩罚）。

要求：
- 给出算法的伪代码
- 分析时间复杂度
- 说明如何从算法输出的独立任务集 $A$ 构造最终的完整调度方案

**答案**：

**核心思路**：最小化总惩罚等价于最大化提前任务的惩罚之和。因此我们将惩罚视为"收益"，在拟阵上运行 Greedy-MAX 找出最大权独立任务集 $A$（提前任务集），其余任务即为延迟任务。

**伪代码**：

```
算法：GREEDY-TASK-SCHEDULING(S, d[1..n], w[1..n])
输入：任务集合 S = {1, 2, ..., n}，截止时间 d[1..n]，惩罚 w[1..n]
输出：最优提前任务集 A（独立集）

1. 将 S 中所有任务按惩罚 w[i] 从大到小排序，得序列 x_1, x_2, ..., x_n
   // 即 w[x_1] ≥ w[x_2] ≥ ... ≥ w[x_n]
2. A ← ∅
3. for i = 1 to n do
4.     令 candidate = A ∪ {x_i}
5.     if candidate 是独立集 then    // 检查 ∀t, N_t(candidate) ≤ t
6.         A ← A ∪ {x_i}
7.     end if
8. end for
9. return A
```

**独立性检查**（子程序）：

```
算法：IS-INDEPENDENT(A, d[1..n])
输入：任务集 A，截止时间 d[1..n]
输出：若 A 是独立集返回 TRUE，否则返回 FALSE

1. 初始化 count[t] = 0 对 t = 1, 2, ..., n
2. for each i ∈ A do
3.     count[d[i]] = count[d[i]] + 1
4. end for
5. total = 0
6. for t = 1 to n do
7.     total = total + count[t]
8.     if total > t then
9.         return FALSE
10.    end if
11. end for
12. return TRUE
```

**复杂度分析**：
- 排序：$O(n \log n)$
- 外层循环 $n$ 次，每次调用独立性检查 $O(n)$
- 总时间复杂度：$O(n \log n + n \cdot n) = O(n^2)$

**构造完整调度方案**：
1. 将提前任务集 $A$ 中的任务按截止时间 $d_i$ 单调递增排序
2. 将延迟任务 $S \backslash A$ 按任意顺序排在提前任务之后
3. 最终调度即为规范形式（Canonical Form），总惩罚等于延迟任务的惩罚之和

### 2. Greedy Theorem 与 Graphic Matroid（15 分）

#### （1）Greedy Theorem for Independent System（6'）

陈述 Greedy Theorem：对于加权独立系统 $(S, C)$，设 $A_G$ 为贪心算法得到的解，$A^*$ 为最优解，则有：

$$1 \le \frac{c(A^*)}{c(A_G)} \le \max_{F \subseteq S} \frac{v(F)}{u(F)}$$

请给出该定理的证明概要。

**答案**：

**Greedy Theorem 证明概要**：

设元素按权值非增排列：$c(x_1) \ge c(x_2) \ge \cdots \ge c(x_n)$。记 $S_i = \{x_1, x_2, \dots, x_i\}$。

**关键引理**：$S_i \cap A_G$ 是 $S_i$ 的一个极大独立子集（maximal independent subset of $S_i$）。

**证明**：贪心算法依次考虑每个元素 $x_j$，若 $x_j$ 能与当前已选集合保持独立则加入。因此当处理完 $S_i$ 中的元素后，$S_i \cap A_G$ 是 $S_i$ 的独立子集，且对任意 $x \in S_i \setminus A_G$，$(S_i \cap A_G) \cup \{x\}$ 不是独立集（否则 $x$ 会被贪心算法加入），故 $S_i \cap A_G$ 是极大独立子集。

由此可得：
$$|S_i \cap A_G| \ge u(S_i) \quad \text{（极大独立子集大小至少为 } u(S_i)\text{）}$$
$$|S_i \cap A^*| \le v(S_i) \quad \text{（任何独立子集大小不超过 } v(S_i)\text{）}$$

**总权值表达**：使用 Telescoping Sum 技巧

$$c(A_G) = \sum_{i=1}^{n-1} |S_i \cap A_G| \cdot (c(x_i) - c(x_{i+1})) + |S_n \cap A_G| \cdot c(x_n)$$
$$c(A^*) = \sum_{i=1}^{n-1} |S_i \cap A^*| \cdot (c(x_i) - c(x_{i+1})) + |S_n \cap A^*| \cdot c(x_n)$$

由于 $c(x_i) - c(x_{i+1}) \ge 0$，代入上界：

$$c(A^*) \le \sum_{i=1}^{n-1} v(S_i) \cdot (c(x_i) - c(x_{i+1})) + v(S_n) \cdot c(x_n)$$
$$\le \rho \cdot \left( \sum_{i=1}^{n-1} u(S_i) \cdot (c(x_i) - c(x_{i+1})) + u(S_n) \cdot c(x_n) \right)$$
$$\le \rho \cdot c(A_G)$$

其中 $\rho = \max_{F \subseteq S} \frac{v(F)}{u(F)}$，即 $c(A^*) \le \rho \cdot c(A_G)$，因此 $\frac{c(A^*)}{c(A_G)} \le \rho$。证毕。

#### （2）Matroid Corollary + MST（5'）

**（a）（2'）** 解释为什么当 $(S, C)$ 是拟阵（Matroid）时，Greedy-MAX 算法一定得到最优解。

**（b）（3'）** 说明如何将最小生成树（MST）问题转化为图拟阵（Graphic Matroid）上的最大权独立集问题，并解释转化后的 Greedy-MAX 等价于 Kruskal 算法。

**答案**：

**（a）拟阵推论**：

当 $(S, C)$ 是拟阵时，对任意 $F \subseteq S$，有 $u(F) = v(F)$。代入 Greedy Theorem：

$$\frac{c(A^*)}{c(A_G)} \le \max_{F \subseteq S} \frac{v(F)}{u(F)} = \max_{F \subseteq S} 1 = 1$$

即 $c(A^*) \le c(A_G)$。又因为 $A^*$ 是最优解，必有 $c(A_G) \le c(A^*)$，因此 $c(A_G) = c(A^*)$，Greedy-MAX 得到最优解。

**（b）MST 转化为图拟阵上的最大权独立集**：

给定连通无向图 $G = (V, E)$，边权 $c(e)$，目标是找一棵总权值最小的生成树。

图拟阵 $M_G = (S, C)$ 定义：$S = E$（所有边），$C = \{F \subseteq E \mid F \text{ 无环}\}$（所有森林）。$M_G$ 中最大权独立集即为最大权森林；当 $|V| = n$ 时，极大独立集的大小为 $n-1$，恰好对应一棵生成树。

MST 是最小化 $\sum_{e \in T} c(e)$，而 Greedy-MAX 是最大化权值。通过**权值变换**可将最小化转为最大化：

定义 $c^*(e) = c_{\max} - c(e)$，其中 $c_{\max} = \max_{e \in E} c(e)$。

- $c^*(e) \ge 0$ 对所有 $e$ 成立
- 对任意生成树 $T$，$\sum_{e \in T} c^*(e) = |T| \cdot c_{\max} - \sum_{e \in T} c(e)$
- 最大化 $\sum c^*(e)$ 等价于最小化 $\sum c(e)$

在 $M_G$ 上以 $c^*$ 为权值运行 Greedy-MAX：
1. 将所有边按 $c^*$ 从大到小排序 $\iff$ 按原始权值 $c$ 从小到大排序
2. 依次检查每条边，若加入后不形成环则保留 $\iff$ Kruskal 算法的核心操作

因此，图拟阵上以 $c^*$ 为权值的 Greedy-MAX 算法与 Kruskal 算法完全等价。

---

#### （3）实例：图拟阵上的 Greedy-MAX（4'）

考虑图 $G = (V, E)$，其中 $V = \{1, 2, 3, 4\}$，边权如下：

| 边 | $e_{12}$ | $e_{13}$ | $e_{14}$ | $e_{23}$ | $e_{24}$ | $e_{34}$ |
|----|----------|----------|----------|----------|----------|----------|
| 权值 $c$ | 5 | 3 | 4 | 6 | 2 | 1 |

**（a）（2'）** 使用 Kruskal 算法求 MST，写出每一步选择的边及最终生成树的总权值。

**（b）（2'）** 进行权值变换 $c^*(e) = c_{\max} - c(e)$，然后在图拟阵 $M_G$ 上运行 Greedy-MAX，验证得到相同的边集。

**答案**：

**（a）Kruskal 算法**：

$c_{\max} = 6$，按权值从小到大排序边：$e_{34}(1), e_{24}(2), e_{13}(3), e_{14}(4), e_{12}(5), e_{23}(6)$

| 顺序 | 边 | 权值 $c$ | 是否成环 | 操作 |
|------|-----|---------|---------|------|
| 1 | $e_{34}$ | 1 | 否 | 选入 |
| 2 | $e_{24}$ | 2 | 否 | 选入 |
| 3 | $e_{13}$ | 3 | 否 | 选入（已达 $n-1 = 3$ 条边，算法终止） |

已选 $\{e_{34}, e_{24}, e_{13}\}$ 连接了所有 4 个顶点（路径 $1\!-\!3\!-\!4\!-\!2$），构成一棵生成树。

**最终 MST**：$\{e_{34}, e_{24}, e_{13}\}$，总权值 $= 1 + 2 + 3 = 6$

（Kruskal 在选满 $n-1 = 3$ 条边后即终止，不需要处理后续边。后续 $e_{14}, e_{12}, e_{23}$ 若加入都会成环。）

**（b）Greedy-MAX 验证**：

权值变换 $c^*(e) = c_{\max} - c(e) = 6 - c(e)$：

| 边 | $e_{12}$ | $e_{13}$ | $e_{14}$ | $e_{23}$ | $e_{24}$ | $e_{34}$ |
|----|----------|----------|----------|----------|----------|----------|
| $c$ | 5 | 3 | 4 | 6 | 2 | 1 |
| $c^*$ | 1 | 3 | 2 | 0 | 4 | 5 |

按 $c^*$ 从大到小排序：$e_{34}(5), e_{24}(4), e_{13}(3), e_{14}(2), e_{12}(1), e_{23}(0)$

| 顺序 | 边 | $c^*$ | 加入后是否独立（无环） | 操作 |
|------|-----|-------|---------------------|------|
| 1 | $e_{34}$ | 5 | 是（单边无环） | 选入 |
| 2 | $e_{24}$ | 4 | 是（$3-4-2$ 无环） | 选入 |
| 3 | $e_{13}$ | 3 | 是（$1-3-4-2$ 无环） | 选入 |
| 4 | $e_{14}$ | 2 | 否（$1-3-4-1$ 成环） | 跳过 |
| 5 | $e_{12}$ | 1 | 否（$1-3-4-2-1$ 成环） | 跳过 |
| 6 | $e_{23}$ | 0 | 否（$2-3-4-2$ 成环） | 跳过 |

Greedy-MAX 最终独立集：$\{e_{34}, e_{24}, e_{13}\}$，与 Kruskal 得到的结果一致。

最大权独立集总权值 $c^* = 5 + 4 + 3 = 12$，对应 MST 总权值 $c = (n-1) \cdot c_{\max} - c^* = 3 \times 6 - 12 = 6$，验证通过。

### 问答题

#### QA1：拟阵与单位时间任务调度

**（1）独立性判定**：$A$ 是独立集 $\iff \forall t = 1,\dots,n,\; N_t(A) \le t$

**（2）Greedy-MAX 算法**：按惩罚降序排序，依次检查加入后是否保持独立；$O(n^2)$；提前任务按截止时间排序即为规范调度

**（3）实例**：
- (a) 最优提前任务集 $A = \{1,2,3,4,7\}$
- (b) 调度 $\langle 2,4,1,3,7,5,6 \rangle$，总惩罚 $50$
- (c) $w_5=80$ 时 $A' = \{5,1,2,3,7\}$，总惩罚 $60$

#### QA2：Greedy Theorem 与 Graphic Matroid

**（1）Greedy Theorem 证明**：关键引理 $S_i \cap A_G$ 是 $S_i$ 的极大独立子集 $\to$ $|S_i \cap A_G| \ge u(S_i),\; |S_i \cap A^*| \le v(S_i)$ $\to$ Telescoping Sum $\to$ $c(A^*) \le \rho \cdot c(A_G)$，其中 $\rho = \max v(F)/u(F)$

**（2a）拟阵推论**：$\forall F,\; u(F)=v(F) \Rightarrow \rho=1 \Rightarrow c(A^*) = c(A_G)$

**（2b）MST 转化**：$c^*(e)=c_{\max}-c(e)$，最大化 $c^*$ 等价于最小化 $c$；按 $c^*$ 降序 $\iff$ 按 $c$ 升序，无环判断 $\iff$ Kruskal

**（3）实例**：MST = $\{e_{34}, e_{24}, e_{13}\}$，总权值 $6$；Greedy-MAX 以 $c^*$ 运行得到相同边集，$c^*$ 总和 $12$，验证 $c = 3\times6 - 12 = 6$
