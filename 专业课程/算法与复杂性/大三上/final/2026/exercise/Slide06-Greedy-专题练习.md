- (A) 按区间长度（$f_j - s_j$）升序选择
- (B) 按最早开始时间（$s_j$）升序选择
- (C) 按最早结束时间（$f_j$）升序选择
- (D) 按冲突数（$c_j$）升序选择

**答案**：C **解析**：幻灯片中给出了各策略的反例：按最早开始时间、最短区间、最少冲突数均不能保证最优解。只有按最早结束时间（Earliest Finish Time）的贪心策略能保证最优解。

**2.（Interval Partitioning, Slide06）** 区间划分（Interval Partitioning）问题中，给定一系列讲座的时间区间，目标是使用最少的教室安排所有讲座。该问题所需的最少教室数等于：

- (A) 讲座的总数
- (B) 所有区间长度的总和
- (C) 所有时间点的最大重叠区间数（即 depth）
- (D) 最晚结束时间

**答案**：C **解析**：设 depth 为所有时间点上同时进行的讲座的最大数量。显然任何时刻的讲座都需要不同的教室，故所需教室数 $\ge$ depth。贪心算法按开始时间排序后，每次分配时若所有已有教室都被占用则开新教室。设贪心算法开了 $d$ 个教室，则第 $d$ 个教室是在处理某个讲座 $j$ 时打开的，此时前 $d-1$ 个教室都已被占用且它们的讲座都与 $j$ 重叠。这些讲座加上 $j$ 共 $d$ 个讲座在 $s_j$ 时刻同时进行，因此 depth $\ge d$。结合下界 depth $\le$ 所需教室数 $= d$，得 $d =$ depth，贪心达到下界，是最优的。

**3.（Scheduling to Minimize Lateness, Slide06）** 在最小化最大延迟（Minimize Maximum Lateness）问题中，每个作业 $j$ 有处理时间 $t_j$ 和截止时间 $d_j$。贪心算法按什么顺序调度作业能够最小化最大延迟？

- (A) 按处理时间 $t_j$ 升序（Shortest Processing Time First）
- (B) 按截止时间 $d_j$ 升序（Earliest Deadline First）
- (C) 按松弛时间 $d_j - t_j$ 升序（Smallest Slack）
- (D) 按处理时间 $t_j$ 降序（Longest Processing Time First）

**答案**：B **解析**：

**Small Slack 的反例**：

| 作业 | $t_j$ | $d_j$ | slack $d_j-t_j$ |
|------|-------|-------|-----------------|
| 1 | 1 | 2 | 1 |
| 2 | 10 | 10 | 0 |

Smallest Slack 先排作业 2（slack=0），后排作业 1：作业 2 $[0,10]$ 延迟 0，作业 1 $[10,11]$ 延迟 $11-2=9$，最大延迟 = 9。

Earliest Deadline First 先排作业 1（$d_1=2$），后排作业 2（$d_2=10$）：作业 1 $[0,1]$ 延迟 0，作业 2 $[1,11]$ 延迟 $11-10=1$，最大延迟 = 1。

**EDF 最优性证明（交换论证）**：

设作业按 deadline 编号 $d_1 \le d_2 \le \dots \le d_n$。EDF 按 $1,2,\dots,n$ 顺序调度，无 idle time，无逆序。

定义逆序（inversion）为 $i < j$ 但 $j$ 排在 $i$ 之前的相邻作业对。设最优解 $OPT$ 是无 idle time 且逆序数最少的调度。若 $OPT$ 有逆序，必存在相邻逆序 $(i,j)$（$i<j$ 但 $j$ 在 $i$ 前）。

交换 $i$ 和 $j$：交换后 $j$ 的完成时间提前，$j$ 的新延迟必然不超过其原来的延迟。$i$ 的完成时间延后到原来 $j$ 的位置，$i$ 的新延迟 $l'_i = f'_i - d_i \le f_j - d_j \le f_j - d_i$（因 $d_i \le d_j$），不增。其他作业延迟不变。故交换不增最大延迟且逆序数减 1，与 $OPT$ 逆序数最少矛盾。因此 $OPT$ 无逆序，与 EDF 相同。

**10.（Cashier's Algorithm 最优性条件, Slide06）** 幻灯片给出了判断贪心找零算法最优性的充分必要条件。设已有 $c_1,\dots,c_t$ 的贪心最优性成立，对于新面额 $c_{t+1} = pc_t - \delta$（$0 \le \delta < c_t$），则贪心算法对新系统也最优的充要条件是：

- (A) $1 + G_t(\delta) \le p$
- (B) $1 + G_t(\delta) \ge p$
- (C) $G_t(\delta) \le 1$
- (D) $\delta = 0$

**答案**：A **解析**：充要条件为 $1 + G_t(\delta) \le p$，其中 $G_t(\delta)$ 是用前 $t$ 种硬币找 $\delta$ 分的贪心硬币数。举例：$c_1=1, c_2=5, c_3=14$ 时 $p=3,\delta=1$，$1+G_2(1)=2\le 3$ 成立，贪心最优。反例：$c_4=18$ 时 $p=2,\delta=10$，$1+G_3(10)=3>2$，贪心不最优（凑 28 分：贪心用 $18+5+5$ 三枚，最优用 $14+14$ 两枚）。

### 1. 分数背包与区间覆盖（18'）

> 参考 Lab02-Q1（Fractional Knapsack）和 Lab02-Q2（Min Interval Covering）

#### （1）分数背包问题（Fractional Knapsack, Greedy, Slide06）（9'）

给定 $n$ 对正实数 $(w_i, v_i)$，分别表示物品 $i$ 的重量和总价值。给定一个容量上限 $W \le \sum_{i=1}^n w_i$，允许拿取物品的任意部分（分数）。目标是最大化总价值：

$$\text{maximize } \sum_{i=1}^n \frac{v_i}{w_i} \cdot x_i$$

约束条件：$0 \le x_i \le w_i$ 且 $\sum_{i=1}^n x_i \le W$。

**（a）**（3'）请设计贪心算法求解该问题，给出伪代码。

**答案**：

```
算法：FRACTIONAL-KNAPSACK(W, w[1..n], v[1..n])
输入：容量 W，n 个物品的重量 w[1..n] 和价值 v[1..n]
输出：每个物品的选取量 x[1..n]

1. 将物品按单位价值 v_i/w_i 从高到低排序
2. 初始化 x[i] = 0 对所有 i
3. i = 1
4. while i ≤ n 且 W > 0 do
5.     x[i] = min(W, w[i])
6.     W = W - x[i]
7.     i = i + 1
8. return x[1..n]
```

**（b）**（3'）分析算法的时间复杂度。

**答案**：排序需要 $O(n \log n)$，分配过程需要 $O(n)$。总时间复杂度为 $O(n \log n)$。

**（c）**（3'）证明该贪心算法的正确性。

**答案**：

**正确性证明**：

设贪心算法选择的物品按单位价值排序为 $1, 2, \dots, n$。令 $x = (x_1, \dots, x_n)$ 为贪心解，$y = (y_1, \dots, y_n)$ 为任意可行解。我们证明贪心解的总价值不低于 $y$ 的总价值。

考虑第一个使 $x_i \ne y_i$ 的下标 $k$。由于贪心算法尽可能多地选取物品 $k$，有 $x_k \ge y_k$。

若 $x_k > y_k$，将 $y$ 中 $k$ 以后的部分物品转换为物品 $k$：减少 $\Delta = x_k - y_k$ 单位后面的物品 $j$（$j > k$），增加同样 $\Delta$ 单位的物品 $k$。因为物品 $k$ 的单位价值 $\ge$ 物品 $j$ 的单位价值，这种转换不降低总价值。重复此过程可将 $y$ 转换为 $x$ 而不降低价值。

因此，贪心解是价值最大的可行解。证毕。

#### （2）最小区间覆盖问题（Min Interval Covering, Greedy, Slide06）（9'）

给定 $n$ 个不同的点 $x_1 < x_2 < \dots < x_n$ 分布在实数轴上，要求用长度为 1 的闭区间覆盖所有这些点，目标是使用尽可能少的区间。

**（a）**（3'）请设计贪心算法，给出伪代码。

**答案**：

```
算法：MIN-INTERVAL-COVER(X[1..n])
输入：n 个点 x_1 < x_2 < ... < x_n
输出：区间集合 I

1. I = ∅, i = 1
2. while i ≤ n do
3.     l = x[i]                    // 新区间左端点
4.     将 [l, l+1] 加入 I
5.     i = i + 1
6.     while i ≤ n 且 x[i] ≤ l+1 do // 跳过被覆盖的点
7.         i = i + 1
8. return I
```

**（b）**（3'）分析算法的时间复杂度。

**答案**：点已排序的情况下，每个点只被访问一次，时间复杂度为 $O(n)$。若点未排序，则需先排序 $O(n \log n)$。

**（c）**（3'）证明该贪心算法的正确性（提示：使用贪心领先或交换论证）。

**答案**：

**正确性证明**：

设贪心算法选择的区间为 $g_1, g_2, \dots, g_p$，其中 $g_k = [x_{i_k}, x_{i_k}+1]$。

设最优解为 $f_1, f_2, \dots, f_q$，其中 $f_k = [a_k, a_k+1]$。假设最优解按左端点升序排列。

**Claim**：存在一个最优解，其第一个区间以 $x_1$ 为左端点。

**证明**：设最优解的第一个区间为 $[a, a+1]$，覆盖了 $x_1$。由于 $a \le x_1 \le a+1$，有 $a+1 \le x_1+1$。因此 $[x_1, x_1+1]$ 覆盖了 $[a, a+1]$ 覆盖的所有点（可能更多）。用 $[x_1, x_1+1]$ 替换 $[a, a+1]$ 得到的新解仍然是可行的且区间数相同。故存在以 $x_1$ 为左端点的最优解。

去掉 $[x_1, x_1+1]$ 覆盖的点后，剩余子问题结构相同。由归纳法，贪心算法每一步都做出与某个最优解一致的选择，因此贪心解就是最优解。证毕。

### 2. 活动选择问题（Activity Selection, 贪心）（15'）

> 参照 2022 高晓沨期末考试 QA2(a) 风格命制

**问题描述**：小明有一台电视机，同一时间只能看一个节目。给定 $n$ 个电视节目，第 $i$ 个节目的开始时间为 $s_i$，结束时间为 $f_i$（$s_i < f_i$）。小明希望看到尽可能多的完整节目（即节目之间不能重叠）。请设计算法帮助小明选择节目。

#### （1）贪心算法设计（5'）

请描述贪心策略，并给出伪代码。分析时间复杂度和空间复杂度。

**答案**：

**贪心策略**：按结束时间最早优先（Earliest Finish Time First）选择节目。每次选择结束时间最早且与已选节目不冲突的节目。

```
算法：ACTIVITY-SELECTION(s[1..n], f[1..n])
输入：n 个节目的开始时间 s[1..n] 和结束时间 f[1..n]
输出：选择的节目下标集合 A

1. 将节目按结束时间 f[i] 升序排序
2. A = {1}                // 第一个节目一定选
3. last_finish = f[1]     // 上一个选中节目的结束时间
4. for i = 2 to n do
5.     if s[i] ≥ last_finish then   // 与已选节目兼容
6.         A = A ∪ {i}
7.         last_finish = f[i]
8. return A
```

**时间复杂度**：排序 $O(n \log n)$，遍历 $O(n)$，总 $O(n \log n)$。
**空间复杂度**：$O(1)$ 额外空间（不计排序所需空间）。

#### （2）正确性证明——交换论证（5'）

请使用**交换论证（Exchange Argument）**证明该贪心算法的最优性。

**答案**：

设贪心算法选择的节目序列为 $G = \{g_1, g_2, \dots, g_k\}$，其中 $g_1$ 是全局结束时间最早的节目，$g_i$ 是在 $g_{i-1}$ 结束后结束时间最早的兼容节目。

设最优解为 $OPT = \{o_1, o_2, \dots, o_m\}$，按结束时间升序排列。显然 $m \ge k$ 否则贪心已最优。

**Claim**：对每个 $r = 1, 2, \dots, k$，存在一个最优解 $OPT_r$ 使得其前 $r$ 个节目与贪心解的前 $r$ 个节目相同。

**证明（归纳法）**：

**归纳基**：$r = 1$。贪心选择 $g_1$ 为结束时间最早的节目，即 $f_{g_1} \le f_{o_1}$。若 $g_1 \neq o_1$，用 $g_1$ 替换 $OPT$ 中的 $o_1$ 得到 $OPT_1$。由于 $f_{g_1} \le f_{o_1}$，$g_1$ 不会与 $o_2$ 冲突（因为 $o_2$ 在 $o_1$ 之后开始），且 $g_1$ 与后面的所有节目兼容。$|OPT_1| = |OPT| = m$，故 $OPT_1$ 仍是最优解。

**归纳步骤**：假设存在最优解 $OPT_{r-1}$ 的前 $r-1$ 个节目与 $g_1, \dots, g_{r-1}$ 相同。设 $OPT_{r-1}$ 的第 $r$ 个节目为 $o_r$。由于贪心选择 $g_r$ 是在 $g_{r-1}$ 结束后结束时间最早的兼容节目，有 $f_{g_r} \le f_{o_r}$。

若 $g_r \neq o_r$，用 $g_r$ 替换 $OPT_{r-1}$ 中的 $o_r$ 得到 $OPT_r$。由于 $f_{g_r} \le f_{o_r}$，$g_r$ 不会与 $o_{r+1}$ 冲突，$OPT_r$ 仍为最优解。

**结论**：由归纳法，存在最优解的前 $k$ 个节目与 $G$ 完全相同。若 $m > k$，则说明在 $g_k$ 结束后还存在兼容节目 $o_{k+1}$，这与贪心算法选择 $g_k$ 后算法终止（即没有更多兼容节目）矛盾。故 $m = k$，贪心解即为最优解。证毕。

#### （3）变体分析——加权区间调度（5'）

现在每个节目有一个"快乐值"$w_i > 0$，小明希望最大化总快乐值而非节目数量。贪心算法（按结束时间最早优先）还能保证最优解吗？如果不能，请设计正确的算法并简要说明思路。

**答案**：

**不能**。贪心算法在加权情况下可能失效。

**反例**：三个节目：
- 节目 A：$[0, 3]$，$w_A = 5$
- 节目 B：$[2, 5]$，$w_B = 100$
- 节目 C：$[4, 7]$，$w_C = 5$

按最早结束时间优先，贪心选择 A 和 C，总快乐值 $5+5=10$。但最优解是只选 B，快乐值 $100$。

**正确算法**：使用**动态规划**（加权区间调度）：

1. 按结束时间排序节目
2. 定义 $p(j) = \max\{i < j \mid f_i \le s_j\}$（与节目 $j$ 兼容的最靠后节目）
3. 递推式：$OPT(j) = \max\{w_j + OPT(p(j)), OPT(j-1)\}$
4. 可用记忆化或自底向上制表法实现，时间复杂度 $O(n \log n)$
