## 一、选择题

**1.（Max-Flow Min-Cut Theorem, Slide14）** 关于最大流最小割定理，以下哪个说法是正确的？

- (A) 最大流的值总是大于最小割的容量
- (B) 对于任意流 f 和任意 s-t 割 (A, B)，总有 v(f) ≥ cap(A, B)
- (C) 流 f 是最大流当且仅当残留网络中不存在增广路径
- (D) 最小割的容量是最大流值的两倍

**答案**：C **解析**：根据讲义，最大流最小割定理等价于以下三者等价：(1) 存在割 (A, B) 使 v(f) = cap(A, B)；(2) f 是最大流；(3) 没有关于 f 的增广路径。A 错，应为相等（强对偶）；B 错，应为 v(f) ≤ cap(A, B)（弱对偶）；D 显然错。

**2.（Ford-Fulkerson Algorithm, Slide14）** Ford-Fulkerson 算法在最坏情况下的时间复杂度是多少？（假设所有容量为不超过 C 的整数，m 为边数，n 为顶点数）

- (A) O(mn)
- (B) O(mnC)
- (C) O(m² log C)
- (D) O(n³)

**答案**：B **解析**：Ford-Fulkerson 算法每次增广至少增加 1 单位流量，最大流值 ≤ nC（因为每条从源点出发的边容量 ≤ C，最多 n 条出边），因此最多进行 O(nC) 次增广。每次用 BFS/DFS 找增广路径需 O(m) 时间，总时间 O(mnC)。该复杂度是伪多项式时间的，因为输入规模含 log C。

---

**3.（Residual Graph, Slide14）** 在 Ford-Fulkerson 算法中，残留网络 Gf 的作用是什么？

- (A) 降低图的空间复杂度
- (B) 确保每次找的增广路径都是最短的
- (C) 提供一种"撤销"已发送流量的机制，允许反向推送流量
- (D) 保证算法终止

**答案**：C **解析**：残留网络 Gf 中每条正向边残留容量为 c(e) − f(e)，反向边残留容量为 f(e)。通过反向边可以"撤销"之前发送的流量，这是 Ford-Fulkerson 克服贪心算法局部最优的关键。讲义明确指出：Need some mechanism to "undo" a bad decision。

**4.（Capacity Scaling, Slide14）** Capacity Scaling 算法将 Ford-Fulkerson 的增广次数从 O(nC) 改进到 O(m log C)，其核心思想是什么？

- (A) 每次选择具有最大瓶颈容量的增广路径
- (B) 每次选择边数最少的增广路径
- (C) 维护缩放参数 Δ，只考虑残留容量 ≥ Δ 的边，每轮结束后 Δ 减半
- (D) 使用 Fibonacci 堆优化优先队列

**答案**：C **解析**：Capacity Scaling 算法维护缩放参数 Δ（初始为 ≥ C 的 2 的幂），在每轮中只考虑残留容量 ≥ Δ 的边构成的子图 Gf(Δ)，找增广路径进行增广，直到 Gf(Δ) 中无增广路径，然后将 Δ 减半。每轮最多进行 2m 次增广，共 O(log C) 轮，总增广次数 O(m log C)。

**5.（Flow Properties, Slide14）** 以下哪个关于流和割的性质是 FALSE？

- (A) 对于任意流 f 和任意 s-t 割 (A, B)，有 v(f) = (流出 A 的流量之和) − (流入 A 的流量之和)
- (B) 若所有容量均为整数，则存在一个最大流 f 使得每条边上的流量均为整数
- (C) 增广路径的瓶颈容量是该路径上残留容量的最大值
- (D) 最大流的值等于最小割的容量

**答案**：C **解析**：C 错，瓶颈容量是路径上残留容量的**最小值**（bottleneck = min residual capacity），而不是最大值。A 正确（Flow Value Lemma）；B 正确（Integrality Theorem）；D 正确（Max-Flow Min-Cut Theorem）。

## 二、问答题

### 1. 最大流与最小割（18'）

#### （1）Flow Value Lemma 与弱对偶性（6'）

设 G = (V, E) 是一个流网络，f 是任意一个 s-t 流，(A, B) 是任意一个 s-t 割。

**（a）** 证明 Flow Value Lemma：v(f) = (流出 A 的流量之和) − (流入 A 的流量之和)。

**（b）** 证明弱对偶性：v(f) ≤ cap(A, B)。

**答案**：

**（a）Flow Value Lemma 证明**：

由流守恒性，对任意非源非汇顶点 v，流出量等于流入量：
```
Σ_{e out of v} f(e) − Σ_{e into v} f(e) = 0
```

将 A 中所有顶点的上述等式求和：
```
v(f) = Σ_{e out of s} f(e) − Σ_{e into s} f(e)
     = Σ_{v∈A} (Σ_{e out of v} f(e) − Σ_{e into v} f(e))
     = Σ_{e out of A} f(e) − Σ_{e into A} f(e)
```

其中第二行到第三行的推导利用了 A 内部的边在求和时一正一负互相抵消，只剩下跨越割的边。

**（b）弱对偶性证明**：

由 Flow Value Lemma：
```
v(f) = Σ_{e out of A} f(e) − Σ_{e into A} f(e)
     ≤ Σ_{e out of A} f(e)        （减去非负项会减小或不变）
     ≤ Σ_{e out of A} c(e)        （流量不超过容量）
     = cap(A, B)
```

因此任意流的值不超过任意割的容量。特别地，最大流的值 ≤ 最小割的容量。

---

#### （2）Max-Flow Min-Cut 定理证明（6'）

证明以下三个命题等价：
1. 存在 s-t 割 (A, B) 使得 v(f) = cap(A, B)
2. f 是最大流
3. 不存在关于 f 的增广路径

**答案**：

**(1) ⇒ (2)**：由弱对偶性，对任意流 f' 有 v(f') ≤ cap(A, B) = v(f)，因此 f 是最大流。同时，对任意割 (A', B') 有 cap(A', B') ≥ v(f) = cap(A, B)，故 (A, B) 是最小割。

**(2) ⇒ (3)**：用反证法。若存在增广路径 P，则可沿 P 增广 δ > 0 单位流量得到流 f'，使 v(f') = v(f) + δ > v(f)，与 f 是最大流矛盾。

**(3) ⇒ (1)**：设 A 为残留网络 Gf 中从 s 可达的顶点集合。由定义 s ∈ A。由于没有增广路径，t ∉ A（否则 s 到 t 有路径即增广路径）。

对任意跨越割的边：
- 若 e = (u, v) 且 u ∈ A, v ∈ B：则 f(e) = c(e)。否则残留容量 c(e) − f(e) > 0，v 将从 u 可达，v ∈ A，矛盾。
- 若 e = (v, w) 且 v ∈ B, w ∈ A：则 f(e) = 0。否则残留容量 f(e) > 0（反向边），v 将从 u 可达（因为 w ∈ A 可达 s，v 可通过反向边到达 w 再到 s），v ∈ A，矛盾。

由 Flow Value Lemma：
```
v(f) = Σ_{e out of A} f(e) − Σ_{e into A} f(e)
     = Σ_{e out of A} c(e) − 0
     = cap(A, B)
```

因此 v(f) = cap(A, B)，证毕。

#### （3）边不相交路径问题（6'）

给定连通有向图 G = (V, E)，源点集合 S = {s₁, s₂, ..., sₖ} 和汇点集合 T = {t₁, t₂, ..., tₖ}（S ∩ T = ∅）。要求找到尽可能多的从 S 中不同起点到 T 中不同终点的路径，且这些路径互不相交（不共享任何边）。

**（a）** 设计算法求最大数量的边不相交路径（8'）
**（b）** 若要求路径既不相交边也不相交顶点（即内部顶点也不重复），如何修改算法？（9'）

**答案**：

**（a）边不相交路径算法**：

构造流网络：
1. 添加超级源点 s* 和超级汇点 t*
2. 从 s* 到每个 sᵢ ∈ S 添加容量为 1 的边
3. 从每个 tⱼ ∈ T 到 t* 添加容量为 1 的边
4. 原图中的每条边赋予容量为 1
5. 所有边的容量均为 1

在该网络上运行 Ford-Fulkerson（或任意最大流算法）求最大流。

**正确性**：
- 每条从 s* 到 t* 的增广路径对应一条从某个 sᵢ 到某个 tⱼ 的路径
- 由于边容量为 1，每条边最多被一条路径使用，保证边不相交
- 从 s* 到每个 sᵢ 的容量为 1，确保每个起点最多被使用一次
- 从每个 tⱼ 到 t* 的容量为 1，确保每个终点最多被使用一次
- 最大流的流量值 = 最大数量的边不相交路径数

**时间复杂度**：O(m · maxflow) = O(m · k)（最大流最多为 k）

**（b）顶点和边均不相交路径算法**：

在（a）的基础上，使用**顶点分裂**（vertex splitting）技术：
- 将每个原图中的顶点 v（非 S ∪ T 中的顶点）分裂为 v_in 和 v_out
- 添加容量为 1 的边从 v_in 到 v_out（限制每个内部顶点最多被一条路径使用）
- 原图中所有入边改为指向 v_in
- 原图中所有出边改为从 v_out 出发

对于 S 和 T 中的顶点：同样分裂，但 s* → sᵢ 连接到 sᵢ_out，tⱼ_in → t* 连接。sᵢ_in → sᵢ_out 和 tⱼ_in → tⱼ_out 的容量也可设为 1（保证起点和终点也唯一使用）。

**正确性**：
- 边容量为 1 保证边不相交（同（a））
- 顶点分裂后内部边的容量为 1 保证每个内部顶点最多被一条路径使用
- 路径不能重复使用顶点（除非路径在该顶点处交汇，但容量 1 禁止了这一点）

**总算法构造图示**：
```
              容量 1                  容量 1
    s* ──→ sᵢ_out ←── sᵢ_in     tⱼ_in ──→ tⱼ_out ──→ t*
              ↓                        ↑
         (原图出边)               (原图入边)
```

### 2. Ford-Fulkerson 算法与改进（15'）

#### （1）算法描述与分析（5'）

写出 Ford-Fulkerson 算法的伪代码，并分析其时间复杂度。指出什么情况下算法会执行大量增广操作。

**答案**：

```
算法 Ford-Fulkerson
输入：流网络 G = (V, E, s, t, c)
输出：最大流 f

1 for each e ∈ E:
2     f(e) = 0
3 构建残留网络 Gf
4 while 存在增广路径 P in Gf:
5     δ = bottleneck(P)    // P 上最小残留容量
6     for each e ∈ P:
7         if e ∈ E:          // 正向边
8             f(e) = f(e) + δ
9         else:               // 反向边
10            f(eR) = f(eR) - δ
11    更新 Gf
12 return f
```

**时间复杂度**：O(m · |f*|)，其中 |f*| 为最大流值。每次增广至少增加 1 单位流量（整数容量时），最坏情况下进行 |f*| 次增广，每次找增广路径需 O(m) 时间。

**指数级增广的反例**：
```
    s ──→ v₁ ──→ t    容量 C
    s ──→ v₂ ──→ t    容量 C
    s ──→ v₁, v₂ ──→ t 容量 1
```
若交替选择 s→v₁→v₂→t 和 s→v₂→v₁→t，每次只增广 1 单位流量，需 2C 次增广。当 C 很大时，算法效率极低。

#### （2）Capacity Scaling 改进（5'）

设计 Capacity Scaling 算法来改进 Ford-Fulkerson 的性能。写出伪代码并分析其增广次数。

**答案**：

```
算法 Capacity Scaling Max-Flow
输入：流网络 G = (V, E, s, t, c)
输出：最大流 f

1 for each e ∈ E:
2     f(e) = 0
3 Δ = 不小于 C 的最小 2 的幂
4 while Δ ≥ 1:
5     构建 Gf(Δ) —— 只包含残留容量 ≥ Δ 的边的子图
6     while Gf(Δ) 中存在从 s 到 t 的路径 P:
7         f = AUGMENT(f, c, P)    // 沿 P 增广
8         更新 Gf(Δ)
9     Δ = Δ / 2
10 return f
```

**增广次数分析**：

**引理 1**：外层循环执行 1 + ⌈log₂ C⌉ 次。因为 Δ 从 ≥ C 的 2 的幂开始，每次除以 2，直到 Δ = 1。

**引理 2**：每轮 Δ-phase 结束时，最大流值 ≤ v(f) + mΔ。证明类似最大流最小割定理：设 A 为 Gf(Δ) 中从 s 可达的顶点集，则跨越割的边满足 f(e) ≥ c(e) − Δ（正向边）和 f(e) ≤ Δ（反向边），从而 v(f) ≥ cap(A, B) − mΔ。

**引理 3**：每轮 Δ-phase 最多进行 2m 次增广。因为上一轮结束时 v(f*) ≤ v(f_prev) + m·(2Δ)，而本轮每次增广至少增加 Δ 流量。

**总增广次数**：O(m · log C)，总时间复杂度 O(m² log C)。

#### （3）Integrality Theorem（5'）

**（a）** 陈述整数性定理（Integrality Theorem）的内容。

**（b）** 证明：若流网络所有边的容量均为整数，则存在一个最大流 f 使得每条边上的流量 f(e) 均为整数。

**（c）** 利用整数性定理，说明如何用最大流解决二分图最大匹配问题。

**答案**：

**（a）整数性定理**：如果流网络 G 中每条边的容量 c(e) 都是整数，则存在一个最大流 f 使得对每条边 e，f(e) 都是整数。

**（b）证明**：Ford-Fulkerson 算法在整数容量下，初始流量 f(e) = 0 为整数。每次增广时，瓶颈容量 δ 是路径上最小残留容量。由于所有残留容量初始为整数（c(e) − 0 = 整数，或 0），且每次增广后流量更新为 f(e) ± δ，只要 δ 为整数，流量保持整数。而 δ 由残留容量的最小值决定，所有残留容量均为整数，故 δ 为整数。由数学归纳法，算法维护了所有 f(e) 为整数的性质。由 Augmenting Path Theorem，算法终止时得到最大流，且各边流量为整数。

**（c）二分图最大匹配**：

给定二分图 G = (L ∪ R, E)，构造流网络：
1. 添加源点 s 和汇点 t
2. 从 s 到每个左部顶点 u ∈ L 添加容量为 1 的边
3. 从每个右部顶点 v ∈ R 到 t 添加容量为 1 的边
4. 对原二分图中的每条边 (u, v)（u ∈ L, v ∈ R），添加容量为 1 的边

在该网络上求最大整数流。由整数性定理，最大流中每条边的流量为 0 或 1。流量为 1 的边 (u, v)（u ∈ L, v ∈ R）构成一个匹配（因为从每个左部顶点出发的流量最多为 1，进入每个右部顶点的流量最多为 1），且匹配的大小等于最大流的值。由最大流最小割定理，该匹配是最大匹配。
