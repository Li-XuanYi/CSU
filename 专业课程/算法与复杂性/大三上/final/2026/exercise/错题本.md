### 1. Insertion Sort 平均情况分析

**出处**：Slide03 专题练习 · 三(1)(b)

假设输入 $A[1, \dots, n]$ 包含 $1$ 到 $n$ 的排列，且所有 $n!$ 种排列等概率出现。求平均情况下插入第 $i$ 个元素 $A[i]$ 时所需的期望比较次数。

**答案**：

插入第 $i$ 个元素时，其正确位置 $j$ 以等概率 $1/i$ 取 $1, 2, \dots, i$ 中的任意值。

- 当 $j = 1$ 时（插入到最前面），需要 $i - 1$ 次比较
- 当 $j \ge 2$ 时，需要 $i - j + 1$ 次比较

期望比较次数为：
$$
\begin{aligned}
E_i &= \frac{i-1}{i} + \sum_{j=2}^{i} \frac{i - j + 1}{i} \\
&= \frac{i-1}{i} + \sum_{k=1}^{i-1} \frac{k}{i} \\
&= \frac{i-1}{i} + \frac{(i-1)i}{2i} \\
&= \frac{i}{2} - \frac{1}{i} + \frac{1}{2}
\end{aligned}
$$

### 2. 杨氏矩阵搜索算法设计与证明

**出处**：Slide03 专题练习 · 四(1)(3)

假设你有一个 $n \times n$ 的二维数组 $A$，其每一行均已按非递减顺序排列，每一列也按非递减顺序排列（即 $A[i][j] \le A[i][j+1]$ 且 $A[i][j] \le A[i+1][j]$）。设计一个算法判断给定值 $x$ 是否存在于数组中，要求时间复杂度为 $O(n)$。给出伪代码，并用循环不变式证明其正确性。

**答案**：

**算法设计**：利用杨氏矩阵（Young Tableau）性质，从右上角开始搜索。

```
Algorithm: SearchYoung(A[·][·], n, x)
Input: n × n 矩阵 A，行列均非递减；目标值 x
Output: 若 x 存在返回 true，否则返回 false

i ← 1
j ← n
while i ≤ n and j ≥ 1 do
    if A[i][j] = x then
        return true
    else if A[i][j] > x then
        j ← j - 1
    else
        i ← i + 1
return false
```

**循环不变式证明**：每次迭代开始时，$x$ 不可能出现在 $A[1..i-1][j+1..n]$ 区域，且 $x$ 一定位于子矩阵 $A[i..n][1..j]$ 中（若存在）。比较 $A[i][j]$ 与 $x$：
- $A[i][j] > x$：第 $j$ 列往下均 $> x$，排除第 $j$ 列，$j \leftarrow j - 1$
- $A[i][j] < x$：第 $i$ 行往左均 $< x$，排除第 $i$ 行，$i \leftarrow i + 1$

不变式保持。当 $i > n$ 或 $j < 1$ 时搜索区域为空，$x$ 不存在。$\square$

### 3. 基于比较的排序算法下界

**出处**：Slide04 专题练习 · 一(8)

基于决策树模型，基于比较的排序算法在最坏情况下的时间复杂度下界是 $\Omega(n \log n)$。

**解析**：

决策树的每个内部节点代表一次比较，每个叶子代表一个可能的排列结果。对 $n$ 个元素排序，共有 $n!$ 种可能的输出，因此决策树必须有至少 $n!$ 个叶子节点。

一棵高度为 $h$ 的二叉树最多有 $2^h$ 个叶子节点，故：

$$2^h \ge n! \quad\Rightarrow\quad h \ge \log_2(n!)$$

使用 Stirling 近似 $\log_2(n!) \approx n\log_2 n - n\log_2 e + O(\log n)$，可得：

$$h = \Omega(n \log n)$$

因此任何基于比较的排序算法在最坏情况下至少需要 $\Omega(n \log n)$ 次比较。

### 4. Master Theorem 递归树证明——每层代价公式

**出处**：Slide04 专题练习 · 一(10)

在 Master Theorem 的递归树证明中，递推 $T(n) = aT(n/b) + O(n^d)$ 的第 $j$ 层（$1 \le j \le \log_b n + 1$）共有 $a^{j-1}$ 个子问题，每个子问题规模为 $n/b^{j-1}$，每个子问题的划分/合并代价为 $O((n/b^{j-1})^d)$。

**第 $j$ 层总代价**：
$$a^{j-1} \times O\!\left(\left(\frac{n}{b^{j-1}}\right)^d\right) = O(n^d) \times \left(\frac{a}{b^d}\right)^{j-1}$$

**三层求和**：
$$T(n) = O(n^d) \sum_{j=0}^{\log_b n} \left(\frac{a}{b^d}\right)^j$$

这是一个公比为 $a/b^d$ 的几何级数。Master Theorem 的三种 case 对应：

| 条件 | 含义 | 几何级数行为 | $T(n)$ |
|------|------|-------------|--------|
| $d > \log_b a$ | $a/b^d < 1$ | 收敛于常数 | $O(n^d)$ |
| $d = \log_b a$ | $a/b^d = 1$ | 每层相同 | $O(n^d \log n)$ |
| $d < \log_b a$ | $a/b^d > 1$ | 末项主导 | $O(n^{\log_b a})$ |

### 5. 最大子数组和——分治算法设计

**出处**：Slide04 专题练习 · 三(3) — Master Theorem 综合应用

设计一个分治算法，在长度为 $n$（$n$ 为 2 的幂）的整数数组 $A[1..n]$ 中找出**最大子数组和**（Maximum Subarray Sum），即找到连续子数组 $A[i..j]$（$1 \le i \le j \le n$）使得其和最大。给出伪代码并分析时间复杂度。

**答案**：

**算法思路**：将数组从中间分为左右两半。最大子数组和可能出现在三个位置：
1. 完全在左半部分 → 递归求解
2. 完全在右半部分 → 递归求解
3. **跨越中点** → 从中点向左右两侧分别扩展，找到最大后缀和 + 最大前缀和

```
算法：MAX-SUBARRAY(A, low, high)
输入：数组 A[low..high]
输出：最大子数组和

1. if low == high then
2.     return A[low]
3. mid = ⌊(low + high) / 2⌋
4.
5. left_sum = MAX-SUBARRAY(A, low, mid)
6. right_sum = MAX-SUBARRAY(A, mid+1, high)
7.
8. // 求跨越中点的最大和
9. sum = 0; max_left = -∞
10. for i = mid downto low do
11.     sum = sum + A[i]
12.     if sum > max_left then max_left = sum
13.
14. sum = 0; max_right = -∞
15. for i = mid+1 to high do
16.     sum = sum + A[i]
17.     if sum > max_right then max_right = sum
18.
19. cross_sum = max_left + max_right
20. return max(left_sum, right_sum, cross_sum)
```

**复杂度分析**：
- 递推关系：$T(n) = 2T(n/2) + O(n)$
- Master Theorem：$a=2$, $b=2$, $d=1$, $\log_b a = 1 = d$ → Case 2 → $T(n) = O(n \log n)$
- 空间复杂度：$O(\log n)$（递归栈）

### 6. Interval Partitioning——最少教室数等于 depth

**出处**：Slide06 专题练习 · 一(2)

区间划分问题中，给定一系列讲座的时间区间，目标是使用最少的教室安排所有讲座。该问题所需的最少教室数等于所有时间点的最大重叠区间数（即 depth）。

**解析**：

设 depth 为所有时间点上同时进行的讲座的最大数量。显然任何时刻的这些讲座都需要不同的教室，故所需教室数 $\ge$ depth。

贪心算法按开始时间升序处理每个讲座，维护每个教室最后一场讲座的结束时间。若当前讲座 $j$ 与所有已有教室的最后一场讲座都冲突（即所有教室的结束时间都 $> s_j$），则开新教室。设贪心算法共开了 $d$ 个教室，则第 $d$ 个教室是在处理某个讲座 $j$ 时打开的。此时前 $d-1$ 个教室的最后一场讲座都还没结束（结束时间 $> s_j$），且因为按开始时间排序，这些讲座的开始时间都 $\le s_j$。因此这 $d$ 场讲座在 $s_j$ 时刻同时进行，故 depth $\ge d$。

结合下界 depth $\le$ 所需教室数 $= d$，得 $d =$ depth，贪心达到下界，是最优的。

### 7. Scheduling to Minimize Lateness——EDF 最优性

**出处**：Slide06 专题练习 · 一(3)

最小化最大延迟问题中，每个作业 $j$ 有处理时间 $t_j$ 和截止时间 $d_j$，贪心策略是按截止时间升序（Earliest Deadline First）调度。

**Small Slack 的反例**：

| 作业 | $t_j$ | $d_j$ | slack $d_j-t_j$ |
|------|-------|-------|-----------------|
| 1 | 1 | 2 | 1 |
| 2 | 10 | 10 | 0 |

Smallest Slack 先排作业 2（slack=0），后排作业 1：作业 2 $[0,10]$ 延迟 0，作业 1 $[10,11]$ 延迟 $11-2=9$，最大延迟 = 9。

Earliest Deadline First 先排作业 1（$d_1=2$），后排作业 2（$d_2=10$）：作业 1 $[0,1]$ 延迟 0，作业 2 $[1,11]$ 延迟 $11-10=1$，最大延迟 = 1。

**EDF 最优性证明（交换论证）**：

设作业按 deadline 编号 $d_1 \le d_2 \le \dots \le d_n$。EDF 按 $1,2,\dots,n$ 顺序调度，无 idle time，无逆序。

定义逆序（inversion）为 $i < j$ 但 $j$ 排在 $i$ 之前的相邻作业对。设最优解 $OPT$ 是无 idle time 且逆序数最少的调度。若 $OPT$ 有逆序，必存在相邻逆序 $(i,j)$（$i<j$ 但 $j$ 在 $i$ 前）。

交换 $i$ 和 $j$：交换后 $j$ 的完成时间提前，$j$ 的新延迟必然不超过其原来的延迟。$i$ 的完成时间延后到原来 $j$ 的位置，$i$ 的新延迟 $l'_i = f'_i - d_i \le f_j - d_j$（因 $d_i \le d_j$），不增。其他作业延迟不变。故交换不增最大延迟且逆序数减 1，与 $OPT$ 逆序数最少矛盾。因此 $OPT$ 无逆序，与 EDF 相同。

### 9. Cashier's Algorithm 最优性充要条件

**出处**：Slide06 专题练习 · 一(10)

已有 $c_1,\dots,c_t$ 满足贪心最优性，对于新面额 $c_{t+1} = pc_t - \delta$（$0 \le \delta < c_t$），贪心算法对新系统也最优的充要条件是 $1 + G_t(\delta) \le p$，其中 $G_t(\delta)$ 是用前 $t$ 种硬币找 $\delta$ 分的贪心硬币数。

**举例**：$c_1=1, c_2=5, c_3=14$ 时 $p=3,\delta=1$，$1+G_2(1)=2\le 3$ 成立，贪心最优。

**反例**：$c_4=18$ 时 $p=2,\delta=10$，$1+G_3(10)=3>2$，贪心不最优（凑 28 分：贪心用 $18+5+5$ 三枚，最优用 $14+14$ 两枚）。

### 10. 分数背包贪心算法正确性证明

**出处**：Slide06 专题练习 · 问答题 1(1)(c)

**问题**：证明分数背包贪心算法（按单位价值降序选取）的正确性。

**答案**：

设贪心算法选择的物品按单位价值排序为 $1, 2, \dots, n$。令 $x = (x_1, \dots, x_n)$ 为贪心解，$y = (y_1, \dots, y_n)$ 为任意可行解。证明贪心解的总价值不低于 $y$ 的总价值。

考虑第一个使 $x_i \ne y_i$ 的下标 $k$。由于贪心算法尽可能多地选取物品 $k$，有 $x_k \ge y_k$。

若 $x_k > y_k$，将 $y$ 中 $k$ 以后的部分物品转换为物品 $k$：减少 $\Delta = x_k - y_k$ 单位后面的物品 $j$（$j > k$），增加同样 $\Delta$ 单位的物品 $k$。因为物品 $k$ 的单位价值 $\ge$ 物品 $j$ 的单位价值，这种转换不降低总价值。重复此过程可将 $y$ 转换为 $x$ 而不降低价值。

因此，贪心解是价值最大的可行解。

### 11. 最小区间覆盖贪心算法正确性证明

**出处**：Slide06 专题练习 · 问答题 1(2)(c)

**问题**：证明最小区间覆盖贪心算法（每次从最左边未覆盖点开始覆盖）的正确性。

**答案**：

设贪心算法选择的区间为 $g_1, g_2, \dots, g_p$，其中 $g_k = [x_{i_k}, x_{i_k}+1]$。

设最优解为 $f_1, f_2, \dots, f_q$，其中 $f_k = [a_k, a_k+1]$。假设最优解按左端点升序排列。

**Claim**：存在一个最优解，其第一个区间以 $x_1$ 为左端点。

**证明**：设最优解的第一个区间为 $[a, a+1]$，覆盖了 $x_1$。由于 $a \le x_1 \le a+1$，有 $a+1 \le x_1+1$。因此 $[x_1, x_1+1]$ 覆盖了 $[a, a+1]$ 覆盖的所有点（可能更多）。用 $[x_1, x_1+1]$ 替换 $[a, a+1]$ 得到的新解仍然是可行的且区间数相同。故存在以 $x_1$ 为左端点的最优解。

去掉 $[x_1, x_1+1]$ 覆盖的点后，剩余子问题结构相同。由归纳法，贪心算法每一步都做出与某个最优解一致的选择，因此贪心解就是最优解。

### 12. 活动选择贪心算法——交换论证

**出处**：Slide06 专题练习 · 问答题 2(2)

**问题**：证明活动选择贪心算法（按最早结束时间优先）的最优性。

**答案**：

设贪心算法选择的节目序列为 $G = \{g_1, g_2, \dots, g_k\}$，其中 $g_1$ 是全局结束时间最早的节目，$g_i$ 是在 $g_{i-1}$ 结束后结束时间最早的兼容节目。

设最优解为 $OPT = \{o_1, o_2, \dots, o_m\}$，按结束时间升序排列。显然 $m \ge k$ 否则贪心已最优。

**Claim**：对每个 $r = 1, 2, \dots, k$，存在一个最优解 $OPT_r$ 使得其前 $r$ 个节目与贪心解的前 $r$ 个节目相同。

**证明（归纳法）**：

**归纳基** $r = 1$：贪心选择 $g_1$ 为结束时间最早的节目，即 $f_{g_1} \le f_{o_1}$。若 $g_1 \neq o_1$，用 $g_1$ 替换 $OPT$ 中的 $o_1$ 得到 $OPT_1$。由于 $f_{g_1} \le f_{o_1}$，$g_1$ 不会与 $o_2$ 冲突（因为 $o_2$ 在 $o_1$ 之后开始），且 $g_1$ 与后面的所有节目兼容。$|OPT_1| = |OPT| = m$，故 $OPT_1$ 仍是最优解。

**归纳步骤**：假设存在最优解 $OPT_{r-1}$ 的前 $r-1$ 个节目与 $g_1, \dots, g_{r-1}$ 相同。设 $OPT_{r-1}$ 的第 $r$ 个节目为 $o_r$。由于贪心选择 $g_r$ 是在 $g_{r-1}$ 结束后结束时间最早的兼容节目，有 $f_{g_r} \le f_{o_r}$。若 $g_r \neq o_r$，用 $g_r$ 替换 $OPT_{r-1}$ 中的 $o_r$ 得到 $OPT_r$。由于 $f_{g_r} \le f_{o_r}$，$g_r$ 不会与 $o_{r+1}$ 冲突，$OPT_r$ 仍为最优解。

**结论**：由归纳法，存在最优解的前 $k$ 个节目与 $G$ 完全相同。若 $m > k$，则说明在 $g_k$ 结束后还存在兼容节目 $o_{k+1}$，这与贪心算法选择 $g_k$ 后算法终止矛盾。故 $m = k$，贪心解即为最优解。

### 13. 活动选择变体——加权区间调度

**出处**：Slide06 专题练习 · 问答题 2(3)

**问题**：每个节目有快乐值 $w_i > 0$，目标最大化总快乐值。贪心算法（最早结束时间优先）还能保证最优吗？如果不能，设计正确算法。

**答案**：

**不能**。反例：
- 节目 A：$[0, 3]$，$w_A = 5$
- 节目 B：$[2, 5]$，$w_B = 100$
- 节目 C：$[4, 7]$，$w_C = 5$

贪心选 A 和 C，总快乐值 $10$；最优解是只选 B，快乐值 $100$。

**正确算法**：动态规划（加权区间调度）
1. 按结束时间排序节目
2. 定义 $p(j) = \max\{i < j \mid f_i \le s_j\}$（与节目 $j$ 兼容的最靠后节目）
3. 递推式：$OPT(j) = \max\{w_j + OPT(p(j)), OPT(j-1)\}$
4. 时间复杂度 $O(n \log n)$

### 14. 0/1 背包判定版本是 NP-complete

**出处**：Slide08 专题练习 · 一(2)(C)

**问题**：证明 0/1 背包问题的判定版本是 NP-complete 的。

**答案**：

0/1 背包的判定版本：给定 $n$ 个物品，每个重量 $w_i$、价值 $v_i$，容量 $W$ 和目标价值 $V$，是否存在子集使得总重量 $\le W$ 且总价值 $\ge V$？

从 SUBSET-SUM 归约。给定 SUBSET-SUM 实例 $\{a_1,\dots,a_n\}$ 和目标值 $t$，构造 0/1 背包实例：
- 令 $w_i = a_i$，$v_i = a_i$（每个物品的重量 = 价值 = $a_i$）
- 令 $W = t$，$V = t$

若 SUBSET-SUM 有解 $S$ 满足 $\sum_{i\in S} a_i = t$，则在背包中选 $S$：总重量 $= t \le W$，总价值 $= t \ge V$，背包有解。反之，若背包有解，则所选子集总重量 $\le t$ 且总价值 $\ge t$，由于 $w_i = v_i$，总重量 $=$ 总价值 $= t$，即 SUBSET-SUM 有解。

因此 SUBSET-SUM $\le_p$ 0/1 背包判定版本。SUBSET-SUM 是已知 NP-complete 问题，故 0/1 背包判定版本也是 NP-complete 的。

### 15. DP 策略分类

**出处**：Slide08 专题练习 · 一(5)

幻灯片总结了 DP 的四种经典技术：

**(A) 加权区间调度 → Binary Choice（二元选择）**
对每个作业 $j$，要么选（获得 $w_j$，递归到 $p(j)$），要么不选（递归到 $j-1$）。每次只有两种决策分支，递推式为 $OPT(j) = \max\{w_j + OPT(p(j)), OPT(j-1)\}$。不是 Multi-way Choice。

**(B) 分段最小二乘法 → Multi-way Choice（多元选择）**
最后一段的起始点 $i$ 可以是 $1$ 到 $j$ 中的任意一个，需要在多个可能的切分点中取最优：$OPT(j) = \min_{1\le i\le j}\{e(i,j) + c + OPT(i-1)\}$。不是 Binary Choice。

**(C) 0/1 背包 → Adding a New Variable（增加新变量）← 正确**
一维子问题 $OPT(i)$（从前 $i$ 个物品中选）不足以描述问题——选了物品 $i$ 后不知道剩余容量，无法判断还能选哪些前面的物品。需要增加容量维度 $w$，得到二维子问题 $OPT(i,w)$。这正是"增加新变量"策略的典型应用。

**(D) RNA 二级结构 → Interval DP（区间 DP）**
子问题 $OPT(i,j)$ 定义在子串 $b_i\cdots b_j$ 上，依赖 $OPT(i,j-1)$ 和 $OPT(i,t-1)+OPT(t+1,j-1)$，属于区间上的 DP。不是 Binary Choice。

### 16. Hirschberg's Algorithm

**出处**：Slide08 专题练习 · 一(9)

Hirschberg 算法将序列比对的空间复杂度从 $O(mn)$ 优化到 $O(m+n)$，核心是将 DP 与分治结合。

标准序列比对 DP 需要 $O(mn)$ 空间存储整个表以回溯路径，而只用两行滚动数组只能算最优值但无法回溯。

Hirschberg 的做法：

1. **分治划分**：将问题在列方向从中间切开，在 $n/2$ 列处找到最优路径经过的行 $q$。

2. **如何找 $q$**：定义 $f(i,j)$ 为从 $(0,0)$ 到 $(i,j)$ 的最短路径长度（前向 DP），$g(i,j)$ 为从 $(i,j)$ 到 $(m,n)$ 的最短路径长度（反向 DP）。计算 $f(\cdot, n/2)$（$O(m)$ 空间）和 $g(\cdot, n/2)$（$O(m)$ 空间），找使 $f(q, n/2) + g(q, n/2)$ 最小的 $q$。从起点到终点的最短路径必然经过 $n/2$ 列上的某个点，$f+g$ 最小化就是找到那个点。

3. **递归求解**：确定了 $(q, n/2)$ 后，将原问题拆为两个子问题：左上 $(0,0)\to(q,n/2)$ 和右下 $(q,n/2)\to(m,n)$，分别递归求解。

4. **复杂度**：每层 $O(mn)$ 时间，递归深度 $O(\log n)$，总时间 $O(mn)$。每层只需 $O(m)$ 空间，递归栈 $O(\log n)$，总空间 $O(m+n)$。

### 17. RNA 二级结构 DP 扫描顺序

**出处**：Slide08 专题练习 · 一(10)

RNA 二级结构的 DP 子问题定义在区间 $[i,j]$ 上，递推关系为：

$$OPT(i,j) = \max\left\{ OPT(i,j-1),\ \max_{i \le t < j-4} \{ 1 + OPT(i,t-1) + OPT(t+1,j-1) \} \right\}$$

$OPT(i,j)$ 依赖于三个子问题：
- $OPT(i,j-1)$：区间长度 $= (j-1) - i = (j-i) - 1$，比原区间短 1
- $OPT(i,t-1)$：区间长度 $= (t-1) - i < (j-4) - i = (j-i) - 4$，至少短 4
- $OPT(t+1,j-1)$：区间长度 $= (j-1) - (t+1) = (j-t) - 2 < (j-i) - 2$，至少短 2

所有依赖的子问题区间长度都严格小于当前区间长度 $j-i$。因此必须按区间长度 $l = j-i$ 从小到大填充 DP 表（沿对角线扫描），才能保证计算 $OPT(i,j)$ 时所需的所有子问题都已被计算过。

三种等价的扫描方式：
- **对角线扫描**：对 $l = 1$ 到 $n-1$，计算所有 $OPT(i, i+l)$
- **水平扫描**：对 $i$ 从 $n$ 递减到 $1$，对 $j$ 从 $i$ 递增到 $n$
- **垂直扫描**：对 $j$ 从 $1$ 递增到 $n$，对 $i$ 从 $j$ 递减到 $1$

### 18. 最长特殊双调子序列——DP 递推与优化

**出处**：Slide08 专题练习 · 问答题 1

**问题**：给定序列 $\{x_1,\dots,x_n\}$，求最长特殊双调子序列长度（增减方向交替，每次变化后恰好一个元素）。

**（1）递推关系**

定义两个 DP 状态：
- $OPT_{\uparrow}(i)$：以 $x_i$ 结尾、最后一步上升的最长长度
- $OPT_{\downarrow}(i)$：以 $x_i$ 结尾、最后一步下降的最长长度

$$OPT_{\uparrow}(i) = 1 + \max_{\substack{1 \le j < i \\ x_j < x_i}} OPT_{\downarrow}(j)$$
$$OPT_{\downarrow}(i) = 1 + \max_{\substack{1 \le j < i \\ x_j > x_i}} OPT_{\uparrow}(j)$$

答案为 $\max_{1\le i\le n}\max\{OPT_{\uparrow}(i), OPT_{\downarrow}(i)\}$。

**（2）伪代码与复杂度**

```
初始化 up[1..n] = 1, down[1..n] = 1
for i = 2 to n:
    for j = 1 to i-1:
        if X[j] < X[i]: up[i] = max(up[i], down[j] + 1)
        if X[j] > X[i]: down[i] = max(down[i], up[j] + 1)
```

时间 $O(n^2)$，空间 $O(n)$。

**（3）优化为 $O(n)$**

从左到右扫描相邻元素，用符号函数 sgn 记录方向，找最长的 $+1/-1$ 交替序列：

```
prev_sign = 0; length = 1
for i = 2 to n:
    sign = sgn(X[i] - X[i-1])
    if sign ≠ 0 and sign ≠ prev_sign:
        length++; prev_sign = sign
```

时间 $O(n)$，空间 $O(1)$。

### 19. Windy World 网格路径计数

**出处**：Slide08 专题练习 · 问答题 2

**问题**：$m \times n$ 网格从 $(0,0)$ 到 $(m-1,n-1)$，可向右或向下移动。进入风力行 $w$ 中的格子会被额外向右推 $s$ 格（不超过 $n-1$）。求路径总数。

**（1）递推关系**

$dp[i][j]$ 为到达 $(i,j)$ 的路径数。采用"推"（push）方式：遍历每个格子，将其路径数推向相邻格子并应用风力。

**（2）伪代码**

```
初始化 dp 为 m×n 零矩阵; dp[0][0] = 1
for i = 0 to m-1:
    for j = 0 to n-1:
        if dp[i][j] == 0: continue
        // 向右
        if j+1 < n:
            nj = j+1
            if i ∈ w: nj = min(nj+s, n-1)
            dp[i][nj] += dp[i][j]
        // 向下
        if i+1 < m:
            nj = j
            if i+1 ∈ w: nj = min(nj+s, n-1)
            dp[i+1][nj] += dp[i][j]
```

时间 $O(mn)$，空间 $O(mn)$（可优化为 $O(n)$）。

**（3）（a）纯递归 vs Tabulation**

纯递归：每一步两种选择，递归树深度 $m+n$，时间 $O(2^{m+n})$，空间 $O(m+n)$（栈深度）。存在大量重复子问题。

Tabulation：时间 $O(mn)$，空间 $O(mn)$。通过避免重复计算将指数级降至多项式时间。

### 20. 0/1 背包——回溯方案

**出处**：Slide08 专题练习 · 问答题 3(3)(a)

**问题**：在 0/1 背包 DP 算法的基础上，设计回溯算法找出具体选择了哪些物品。

**答案**：

```
算法：FIND-SELECTED(t[1..n], h[1..n], T, dp)
输入：n 个物品的时间、价值，总容量 T，已填好的 dp 表
输出：被选中的物品下标集合 S

1. S = ∅
2. i = n, w = T
3. while i > 0 and w > 0 do
4.     if dp[i][w] ≠ dp[i-1][w] then
5.         S = S ∪ {i}
6.         w = w - t[i]
7.     i = i - 1
8. return S
```

**原理**：如果 $dp[i][w] \neq dp[i-1][w]$，说明第 $i$ 个物品被选中了（选比不选价值更高），此时扣除其时间并继续检查前 $i-1$ 个物品。

时间复杂度 $O(n)$。

### 21. Domain Conversion Lemma（定义域转换引理）

**出处**：Slide05 专题练习 · 问答题 2(1)

**引理内容**：设比较网络将输入 $a = \langle a_1,\dots,a_n \rangle$ 变换为输出 $b = \langle b_1,\dots,b_n \rangle$，则对任意**单调递增函数** $f$，该网络将输入 $f(a) = \langle f(a_1),\dots,f(a_n) \rangle$ 变换为输出 $f(b) = \langle f(b_1),\dots,f(b_n) \rangle$。

**证明（对 wire depth 归纳）**：

先证单个 comparator 的 Claim：对输入 $x,y$，上输出 = $\min\{x,y\}$，下输出 = $\max\{x,y\}$。由于 $f$ 单调递增，$x \le y \implies f(x) \le f(y)$，故：
- $\min\{f(x), f(y)\} = f(\min\{x, y\})$
- $\max\{f(x), f(y)\} = f(\max\{x, y\})$

**归纳基础**（depth = 0）：深度为 0 的导线是输入导线。当输入为 $a$ 时导线值为 $a_i$，当输入为 $f(a)$ 时导线值为 $f(a_i)$。成立。

**归纳步骤**：假设对 depth $< d$ 的所有导线结论成立。考虑一条 depth = $d$ 的导线，它是某 depth $d$ 的 comparator 的输出线，该 comparator 的两条输入导线 depth 均 $< d$。由归纳假设，这些输入导线在输入 $a$ 和 $f(a)$ 时分别承载 $(a_i, a_j)$ 和 $(f(a_i), f(a_j))$。由 Claim，输出在输入 $f(a)$ 时为 $f(\min\{a_i,a_j\})$ 和 $f(\max\{a_i,a_j\})$，恰好是原输出 $(\min,\max)$ 的 $f$ 映射。引理证毕。

### 22. Zero-One Principle（0-1 原理）

**出处**：Slide05 专题练习 · 问答题 2(2)

**定理内容**：若一个 $n$ 输入的比较网络能正确排序所有 $2^n$ 种 0-1 序列，则它能正确排序任意实数序列。

**证明（反证法 + Domain Conversion Lemma）**：

假设网络能正确排序所有 0-1 序列，但存在实数序列 $a = \langle a_1,\dots,a_n \rangle$ 排序失败，即存在 $a_i < a_j$ 但输出中 $a_j$ 在 $a_i$ 之前。定义单调函数：
$$
f(x) = \begin{cases}
0, & x \le a_i \\
1, & x > a_i
\end{cases}
$$
则 $f(a)$ 是 0-1 序列，且 $f(a_i)=0$，$f(a_j)=1$。

由 Domain Conversion Lemma，输入 $f(a)$ 时输出为 $f(b)$（$b$ 是原输出）。由于原输出中 $a_j$ 在 $a_i$ 前，$f(b)$ 中 $f(a_j)=1$ 在 $f(a_i)=0$ 前。这意味网络对 $f(a)$ 也未正确排序，与"所有 0-1 序列都能正确排序"矛盾。$\square$

**意义**：将验证排序网络正确性的无穷多种实数输入归约为有限的 $2^n$ 种 0-1 输入。

### 23. Zero-One Principle 的应用——4 输入排序网络验证

**出处**：Slide05 专题练习 · 问答题 2(3)

给定 4 输入比较网络 comparators：$(1,2), (3,4), (1,3), (2,4)$。

由 Zero-One Principle，只需验证全部 $2^4 = 16$ 种 0-1 输入。对所有 0-1 输入追踪 comparators 的执行，输出均为升序，故该网络是排序网络。

不能只测一条 0-1 序列：反证法构造的 $f(a)$ 由具体实数序列 $a$ 决定，只测固定一条无法覆盖所有可能构造出的 0-1 序列。

### 24. Sorting Network 三种组件深度对比

| 网络 | 递归构造 | 深度递推式 | 深度 |
|------|----------|-----------|------|
| BITONIC-SORTER[n] | HALF-CLEANER[n] + 两个 BITONIC-SORTER[n/2] | D(n) = D(n/2) + 1 | O(log n) |

### 25. 对偶转换规则（min → max）

**出处**：Slide09 专题练习 · 问答题 1(1)

标准 min primal 形式为 $\min c^T x$ s.t. $Ax \ge b, x \ge 0$，其对偶是 $\max b^T y$ s.t. $A^T y \le c, y \ge 0$。由此推导出的完整规则表：

| Primal (min) | Dual (max) |
|---|---|
| min | max |
| $=$ 约束 | 对应变量无限制 |
| $\ge$ 约束 | 对应变量 $\ge 0$ |
| $\le$ 约束 | 对应变量 $\le 0$ |
| 变量 $\ge 0$ | 对应约束为 $\le$ |
| 变量无限制 | 对应约束为 $=$ |
| 变量 $\le 0$ | 对应约束为 $\ge$ |

**示例**：将以下 min primal 转为 dual
```
min  z = 4x₁ + 3x₂
s.t. x₁ + 2x₂ = 10
     3x₁ + x₂ ≥ 15
     x₁ ≥ 0, x₂ 无限制
```

逐条推导：
1. min → max
2. 第 1 个约束 $=$ → $y_1$ 无限制；第 2 个约束 $\ge$ → $y_2 \ge 0$
3. $x_1 \ge 0$ → 第 1 个 dual 约束为 $\le$；$x_2$ 无限制 → 第 2 个 dual 约束为 $=$
4. 系数转置：$y_1 + 3y_2 \le 4$（对应 $x_1$），$2y_1 + y_2 = 3$（对应 $x_2$）
5. Primal 右端项 $(10, 15)$ 成为 dual 目标系数

结果：
```
max  w = 10y₁ + 15y₂
s.t. y₁ + 3y₂ ≤ 4
     2y₁ + y₂ = 3
     y₁ unrestricted, y₂ ≥ 0
```

### 26. 弱对偶定理证明

**出处**：Slide09 专题练习 · 问答题 1(2)

**定理**：若 $x$ 是 primal (max) 的可行解，$y$ 是 dual (min) 的可行解，则 $c^T x \le b^T y$。

**证明**：

设 primal：$\max c^T x$ s.t. $Ax \le b, x \ge 0$
dual：$\min b^T y$ s.t. $A^T y \ge c, y \ge 0$

由于 $y \ge 0$，左乘 primal 约束 $Ax \le b$：$y^T A x \le y^T b = b^T y$
由于 $x \ge 0$，左乘 dual 约束 $A^T y \ge c$：$x^T A^T y \ge x^T c = c^T x$，即 $y^T A x \ge c^T x$
联立：$c^T x \le y^T A x \le b^T y$，证毕。

**推论**：
- primal 无界 $\Rightarrow$ dual 不可行
- dual 无界 $\Rightarrow$ primal 不可行
- $c^T x = b^T y$ $\Rightarrow$ $x$, $y$ 分别是最优解（强对偶定理）

### 27. ILP 建模：独立集、支配集、顶点覆盖

**出处**：Slide09 专题练习 · 问答题 1(3) + 问答题 2(2)

**（a）最大独立集（Maximum Independent Set）**
```
max  Σ_{u∈V} x_u
s.t. x_u + x_v ≤ 1,  ∀ (u, v) ∈ E
     x_u ∈ {0, 1},   ∀ u ∈ V
```
含义：相邻顶点不能同时被选（排斥约束 $\le$）。

**（b）最小支配集（Minimum Dominating Set）**
```
min  Σ_{u∈V} x_u
s.t. x_u + Σ_{v∈N(u)} x_v ≥ 1,  ∀ u ∈ V
     x_u ∈ {0, 1},              ∀ u ∈ V
```
含义：每个顶点要么自身被选，要么至少一个邻居被选（覆盖约束 $\ge$）。

**（c）最小顶点覆盖（Minimum Vertex Cover）**
```
min  Σ_{u∈V} x_u
s.t. x_u + x_v ≥ 1,  ∀ (u, v) ∈ E
     x_u ∈ {0, 1},   ∀ u ∈ V
```
含义：每条边至少有一个端点被选中。

**独立集与顶点覆盖的关系**：$S$ 是独立集 $\iff$ $V \setminus S$ 是顶点覆盖。证明：若 $x$ 是独立集可行解，则 $y = 1 - x$ 是顶点覆盖可行解，因为 $y_u + y_v = 2 - (x_u + x_v) \ge 2 - 1 = 1$。

### 28. 单纯形法完整两轮 Pivot

**出处**：Slide09 专题练习 · 问答题 2(1)

**问题**：$\max z = 3x_1 + 5x_2$ s.t. $x_1 + x_2 \le 4$, $x_1 \le 2$, $x_2 \le 3$, $x_1,x_2 \ge 0$

**（a）Slack Form**：引入松弛变量 $x_3,x_4,x_5$：
```
max  z = 3x₁ + 5x₂
s.t. x₁ + x₂ + x₃ = 4
     x₁ + x₄ = 2
     x₂ + x₅ = 3
     x₁,x₂,x₃,x₄,x₅ ≥ 0
```
非基变量：$x_1,x_2$；基变量：$x_3,x_4,x_5$
初始基本可行解：$(0,0,4,2,3)$，$z=0$

**（b）第 1 轮 Pivot**：
- 选 $x_2$ 入基（系数 5 > 3），最紧约束 $x_5$：$x_2 \le 3$，$x_5$ 出基
- 代入 $x_2 = 3 - x_5$ 到各等式
- 结果：$z = 15 + 3x_1 - 5x_5$，非基 $x_1,x_5$，基 $x_2,x_3,x_4$
- 基本可行解：$(0,3,1,2,0)$，$z=15$

**（c）第 2 轮 Pivot**：
- $x_1$ 系数 3 > 0，入基；最紧约束 $x_3$：$x_1 \le 1$，$x_3$ 出基
- 代入 $x_1 = 1 - x_3 + x_5$
- 结果：$z = 18 - 3x_3 - 2x_5$，所有系数 $\le 0$，终止
- 非基：$x_3,x_5$；基：$x_1,x_2,x_4$
- 最优解：$(x_1,x_2) = (1,3)$，$z=18$

**Pivot 终止条件**：当 Slack Form 中目标函数的所有非基变量系数 $\le 0$ 时，当前基本可行解即为最优解。因为任何增大非基变量的操作都会降低目标值。

### 30. 拟阵定义与四种系统辨析

**出处**：Slide07 专题练习 · 一(1)

拟阵 (Matroid) 须满足两个性质：**遗传性** + **交换性质**。

| 系统 | 遗传性 | 交换性质 | 是拟阵？ |
|------|--------|---------|---------|
| 矩阵拟阵 (线性无关行向量) | 线性无关组子集仍无关 ✓ | dim(span(A)) < dim(span(B)) ⇒ ∃x∈B\span(A) ✓ | 是 |

### 31. $u(F)$ 与 $v(F)$ 拟阵定理

**出处**：Slide07 专题练习 · 一(2)

**定义**：
- $u(F) = \min\{|I| \mid I \text{ 是 } F \text{ 的极大独立子集}\}$
- $v(F) = \max\{|I| \mid I \text{ 是 } F \text{ 的独立子集}\}$

**Matroid Theorem**（讲义 page 17）：$(S, C)$ 是拟阵 $\iff$ 对任意 $F \subseteq S$，$u(F) = v(F)$。

证明方向：
- (⇒) 若 $F$ 有两个极大独立子集 $|A| < |B|$，交换性质 ⇒ ∃x∈B使A∪{x}独立，与 A 的极大性矛盾
- (⇐) 假设对所有 $F \subseteq S$ 有 $u(F) = v(F)$，要证交换性质成立。取任意两个独立集 $A, B$ 满足 $|A| < |B|$，令 $F = A \cup B$。由于 $B \subseteq F$ 且 $B$ 独立，故 $v(F) \ge |B|$；由条件 $u(F) = v(F)$ 得 $u(F) \ge |B|$，即 $F$ 的所有极大独立子集大小都 $\ge |B| > |A|$。这意味着 $A$ **不是** $F$ 的极大独立子集，因此 $A$ 在 $F$ 中必有扩展——即存在元素 $x \in F \setminus A$ 使得 $A \cup \{x\} \in C$。由于 $F \setminus A = (A \cup B) \setminus A = B \setminus A$，该元素 $x$ 必然来自 $B \setminus A$。这正是交换性质所要求的。$\square$

**应用**：若存在某个 $F$ 使 $u(F) \neq v(F)$，则该系统一定不是拟阵。

### 32. Greedy-MAX 与拟阵等价定理

**出处**：Slide07 专题练习 · 一(3)

**Greedy Theorem**（讲义 page 24）：对加权独立系统，$1 \le \dfrac{c(A^*)}{c(A_G)} \le \max\limits_{F\subseteq S} \dfrac{v(F)}{u(F)}$。

**拟阵推论**：$(S,C)$ 是拟阵时 $\forall F,\ u(F)=v(F) \Rightarrow \rho=1 \Rightarrow c(A_G)=c(A^*)$，Greedy-MAX 最优。

**逆定理**（讲义 page 34-35）：若 Greedy-MAX 对任意权值都给出最优解，则 $(S,C)$ 是拟阵。即拟阵与 Greedy-MAX 最优性等价。

**常见误区**：Greedy-MAX 在一般独立系统上**不能**保证最优解，只保证性能比 $\le \rho$。

### 33. 单位时间任务调度——独立性判定与 Greedy-MAX

**出处**：Slide07 专题练习 · 问答题 1

**问题**：$n$ 个任务，每个需 1 单位时间，截止时间 $d_i$，惩罚 $w_i$。最小化总惩罚。

**独立性充要条件**：$A$ 是独立集 $\iff \forall t = 1,\dots,n,\ N_t(A) \le t$（$N_t(A)$ 为 $A$ 中截止时间 $\le t$ 的任务数）。

**Greedy-MAX 算法**：
1. 按惩罚降序排序
2. 依次尝试加入每个任务，用 $N_t(A) \le t$ 检查独立性
3. 选出最优提前任务集 $A$，其余为延迟任务
4. 时间复杂度 $O(n^2)$

**实例**（7 个任务，$d=[4,2,4,3,1,4,6], w=[70,60,50,40,30,20,10]$）：
- 最优提前任务集 $A = \{1,2,3,4,7\}$
- 调度 $\langle 2,4,1,3,7,5,6 \rangle$，总惩罚 $w_5+w_6=50$
- 若 $w_5=80$，$A' = \{5,1,2,3,7\}$，总惩罚 $w_4+w_6=60$

### 34. Greedy Theorem 证明概要

**出处**：Slide07 专题练习 · 问答题 2(1)

设元素按 $c(x_1) \ge c(x_2) \ge \dots \ge c(x_n)$，$S_i = \{x_1,\dots,x_i\}$。

**关键引理**：$S_i \cap A_G$ 是 $S_i$ 的极大独立子集。⇒ $|S_i \cap A_G| \ge u(S_i)$，$|S_i \cap A^*| \le v(S_i)$。

**Telescoping Sum 技巧**：
$$c(A_G) = \sum_{i=1}^{n-1} |S_i \cap A_G| \cdot (c(x_i)-c(x_{i+1})) + |S_n \cap A_G| \cdot c(x_n)$$

代入上下界，令 $\rho = \max_{F\subseteq S} \frac{v(F)}{u(F)}$，得 $c(A^*) \le \rho \cdot c(A_G)$。

**拟阵时**：$\rho = 1$ ⇒ $c(A_G) = c(A^*)$，Greedy-MAX 最优。

### 35. MST → 图拟阵上的 Greedy-MAX

**出处**：Slide07 专题练习 · 问答题 2(2)(3)

**权值变换**：$c^*(e) = c_{\max} - c(e)$，最大化 $\sum c^*$ 等价于最小化 $\sum c$。

**图拟阵 $M_G$**：$S = E$，$C = \{\text{无环边集}\}$。极大独立子集（base）= 生成树。

**等价性**：
- 按 $c^*$ 降序排列 $\iff$ 按 $c$ 升序排列（Kruskal 的排序）
- 检查加入后是否无环 $\iff$ Kruskal 的环检测
- Greedy-MAX 选出的最大权独立集 = Kruskal 选出的 MST

**实例**（4 顶点完全图，$c=[5,3,4,6,2,1]$）：
- MST = $\{e_{34}, e_{24}, e_{13}\}$，总权值 $1+2+3=6$
- 验证：$c^*=[1,3,2,0,4,5]$，Greedy-MAX 按 $c^*$ 降序选 $\{e_{34}, e_{24}, e_{13}\}$，$c^*$ 和 $12$，$c = 3\times6 - 12 = 6$ ✓

### 37. 二进制计数器与多栈的摊还分析

**出处**：Slide10 专题练习 · 问答题 2

**（1）聚集分析**：位 $A[i]$ 每 $2^i$ 次 INCREMENT 翻转一次，$T(n) = \sum \lfloor n/2^i \rfloor < 2n$，摊还 $O(1)$。从任意 $m$ 开始计数到 $n$ 时，$T \le \sum \lceil L/2^i \rceil < 2L + k = O(L)$，摊还仍 $O(1)$。

**（2a）记账法**：flip($0\to1$) 收 $2$（$1$ 用于本次，$1$ 存储为信用），flip($1\to0$) 收 $0$。信用总量 $=$ 计数器中 1 的个数 $\ge 0$。总摊还 $\le 2n$。

**（2b）势能法**：$\Phi = \#1$，$\hat{C}_i = (t_i+1) + (1-t_i) = 2$。$\Phi \ge \Phi_0 = 0$，满足条件。

**（3）Multistack Push**：$S_i$ 容量 $2^i$，每 $2^i$ 次 push 触发一次迁移（代价 $2^{i+1}$）。$T(n) = n + \sum_{i=0}^{\log n} \lfloor n/2^i \rfloor \times 2^{i+1} = O(n\log n)$，摊还 $O(\log n)$。

### 40. 动态表势能函数设计（1/3-2/3 阈值）

**出处**：Slide10 专题练习 · 问答题 1(4)

扩容阈值 $\alpha > 2/3$，缩容阈值 $\alpha < 1/3$。

势能函数：
$$
\Phi(T) = \begin{cases}
4\cdot\text{num} - 2\cdot\text{size}, & \alpha \ge 1/2 \\[4pt]
\text{size} - 2\cdot\text{num}, & \alpha < 1/2
\end{cases}
$$

**设计原理**：在 $\alpha=1/2$ 处 $\Phi=0$，在 $\alpha=2/3$ 处 $\Phi=\text{num}$（覆盖扩容复制代价），在 $\alpha=1/3$ 处 $\Phi=\text{num}$（覆盖缩容复制代价）。所有系数通过解方程组得到。

**验证非负性**：$\alpha \ge 1/2$ 时 $\Phi \ge 4\cdot\frac{\text{size}}{2} - 2\cdot\text{size} = 0$；$\alpha < 1/2$ 时 $\Phi > \text{size} - 2\cdot\frac{\text{size}}{2} = 0$。
