**1.（Duality Conversion, Slide09）** 给定以下线性规划 Primal 问题：

```
max  z = 3x₁ + 2x₂
s.t. x₁ + x₂ ≥ 5
     2x₁ + x₂ ≤ 12
     x₁, x₂ ≥ 0
```

将其转化为 Dual 问题，正确的是：

- (A) `min 5y₁ + 12y₂  s.t. y₁ + 2y₂ ≥ 3, y₁ + y₂ ≥ 2, y₁ ≤ 0, y₂ ≥ 0`
- (B) `min 5y₁ + 12y₂  s.t. y₁ + 2y₂ ≤ 3, y₁ + y₂ ≤ 2, y₁ ≥ 0, y₂ ≥ 0`
- (C) `min 5y₁ + 12y₂  s.t. y₁ + 2y₂ ≥ 3, y₁ + y₂ ≥ 2, y₁ ≥ 0, y₂ ≤ 0`
- (D) `min 5y₁ + 12y₂  s.t. y₁ + 2y₂ ≥ 3, y₁ + y₂ ≥ 2, y₁ ≥ 0, y₂ ≥ 0`

**答案**：A **解析**：

本题考查 max 形式 primal 向 dual 的转换规则。先完整写出对偶转换规则表：

| Primal (max) | Dual (min) |
|---|---|
| max | min |
| 第 $i$ 个约束为 $\le$ | 对应 $y_i \ge 0$ |
| 第 $i$ 个约束为 $=$ | 对应 $y_i$ 无限制 |
| 第 $i$ 个约束为 $\ge$ | 对应 $y_i \le 0$ |
| $x_j \ge 0$ | 对应第 $j$ 个约束为 $\ge$ |
| $x_j$ 无限制 | 对应第 $j$ 个约束为 $=$ |
| 目标系数 $c_j$ | 成为 dual 约束右端项 |
| 约束右端项 $b_i$ | 成为 dual 目标系数 |

**对本题应用**：

Primal 问题：
```
max  z = 3x₁ + 2x₂
s.t. x₁ + x₂ ≥ 5      ← 第 1 个约束，≥ 方向
     2x₁ + x₂ ≤ 12    ← 第 2 个约束，≤ 方向
     x₁, x₂ ≥ 0
```

逐条推导 Dual：

1. **Dual 目标**：Primal 是 max，故 Dual 是 min。Primal 的右端项 $(5, 12)$ 成为 Dual 目标系数 → $5y_1 + 12y_2$。

2. **Dual 变量**：Primal 有 2 个约束 → Dual 有 2 个变量 $y_1, y_2$。
   - 第 1 个约束是 $\ge$ → $y_1 \le 0$
   - 第 2 个约束是 $\le$ → $y_2 \ge 0$

3. **Dual 约束**：Primal 有 2 个变量 $x_1, x_2 \ge 0$ → Dual 有 2 个约束，方向均为 $\ge$（因为 $x_j \ge 0$）。
   - 对应 $x_1$：$a_{11}y_1 + a_{21}y_2 \ge c_1$ → $1\cdot y_1 + 2\cdot y_2 \ge 3$ 即 $y_1 + 2y_2 \ge 3$
   - 对应 $x_2$：$a_{12}y_1 + a_{22}y_2 \ge c_2$ → $1\cdot y_1 + 1\cdot y_2 \ge 2$ 即 $y_1 + y_2 \ge 2$

4. **完整 Dual**：
```
min  5y₁ + 12y₂
s.t. y₁ + 2y₂ ≥ 3
     y₁ + y₂ ≥ 2
     y₁ ≤ 0, y₂ ≥ 0
```

选项 A 与此一致。常见错误：忘记 $\ge$ 约束对应的 dual 变量应为 $\le 0$（选项 D 错误地将两个变量都设为 $\ge 0$），或混淆矩阵转置的方向（选项 B 将约束方向弄反）。

**2.（Weak & Strong Duality, Slide09）** 对于一对 primal-dual 线性规划问题，以下说法中正确的是：

- (A) 若 primal 无界，则 dual 一定也无界
- (B) 弱对偶定理表明：若 primal 和 dual 均有可行解，则它们的最优目标函数值一定相等
- (C) 若 x 和 y 分别是 primal 和 dual 的可行解，且 c^T x = b^T y，则 x 和 y 分别是 primal 和 dual 的最优解
- (D) 若 primal 的可行域非空，则 primal 一定有最优解

**答案**：C **解析**：

对每一选项逐一分析：

**选项 (A) 错误**。弱对偶定理告诉我们：若 primal 是 max、dual 是 min，则对任意可行解 $x$ 和 $y$ 有 $c^T x \le b^T y$。若 primal 无界（$c^T x \to +\infty$），则不可能存在有限大的 $b^T y$ 来上界它，因此 dual 不可行（无可行解）。反之，若 dual 无界（$b^T y \to -\infty$），则 primal 不可行。所以"primal 无界 $\Rightarrow$ dual 无界"是错误的，正确结论是"primal 无界 $\Rightarrow$ dual 不可行"。

**选项 (B) 错误**。弱对偶定理只给出不等式 $c^T x \le b^T y$，不能保证相等。这里的"gap"称为对偶间隙（duality gap）。若 primal 和 dual 都有可行解，最优值之间可能存在间隙，由弱对偶定理只能推出 $\max c^T x \le \min b^T y$。只有当强对偶定理成立（LP 问题满足强对偶性）时，才有 $\max c^T x = \min b^T y$。

**选项 (C) 正确**。这就是强对偶定理的直接推论。强对偶定理说：若 primal 或 dual 中一个有最优解，则另一个也有最优解，且最优值相等。题设中 $c^T x = b^T y$，由弱对偶定理，任何其他可行解 $x'$ 满足 $c^T x' \le b^T y = c^T x$（$x$ 是 primal 中最大的），任何其他可行解 $y'$ 满足 $b^T y' \ge c^T x = b^T y$（$y$ 是 dual 中最小的），故 $x$ 和 $y$ 分别是 primal 和 dual 的最优解。

**选项 (D) 错误**。可行域非空（即可行解存在）是必要条件但不是充分条件。LP 问题可能有无界解（unbounded）：目标函数值可以无限增大（对 max 问题）或无限减小（对 min 问题）。例如：$\max\{x_1 + x_2 \mid x_1 - x_2 \le 1, x_1, x_2 \ge 0\}$ 的可行域非空，但目标值可以无限增大（固定 $x_1 = 0$，让 $x_2 \to \infty$），因此没有有限最优解。

**3.（Integer Linear Programming, Slide09）** 关于整数线性规划 (ILP)，以下说法中正确的是：

- (A) ILP 是 LP 的一个特例，因此可以用单纯形法高效求解
- (B) 最大独立集问题（Maximum Independent Set）可以建模为 ILP：max Σxᵤ  s.t. xᵤ + xᵥ ≤ 1  ∀(u,v)∈E, xᵤ∈{0,1}
- (C) ILP 与 LP 的唯一区别在于 ILP 要求变量为非负整数，这一限制不会影响问题的计算复杂度
- (D) 支配集问题（Dominating Set）可以建模为 ILP：min Σxᵤ  s.t. xᵤ + Σᵥ∈N(u) xᵥ ≤ 1  ∀u∈V, xᵤ∈{0,1}

**答案**：B **解析**：

对每一选项逐一分析：

**选项 (A) 错误**。ILP（整数线性规划）不是 LP 的特例——恰恰相反，ILP 是在 LP 的基础上增加了整数约束，这使问题难度大幅提升。LP 可以在多项式时间内求解（如椭球算法、内点法），而 ILP 是 NP 问题，没有已知的多项式时间算法。单纯形法可以求解 LP 的松弛版本（即去掉整数约束后的 LP），但不能直接求解 ILP。

**选项 (B) 正确**。最大独立集（Maximum Independent Set）要求选出互不相邻的顶点，最大化选中的顶点数。其 ILP 建模为：
- 变量：$x_u \in \{0,1\}$，$x_u = 1$ 表示顶点 $u$ 被选入独立集
- 目标：$\max \sum_{u \in V} x_u$（最大化选中顶点数）
- 约束：$x_u + x_v \le 1$ 对所有边 $(u,v) \in E$——相邻顶点不能同时被选。因为若 $x_u = 1$，则 $x_v$ 必须为 0，反之亦然

这是标准的 ILP 建模，正确。

**选项 (C) 错误**。ILP 与 LP 的整数约束不是"不会影响计算复杂度"的微小差异。LP 属于 P 类问题（可在多项式时间内求解），而 ILP 是 NP-complete 的。这一"整数 vs 实数"的差异使问题从多项式跳到了指数级难度。实际上，许多 NP-complete 问题都可以自然地建模为 ILP（如独立集、顶点覆盖、旅行商问题等），这暗示了 ILP 的 NP 难度。

**选项 (D) 错误**。支配集（Dominating Set）的约束是"每个顶点要么自身被选，要么至少有一个邻居被选"，数学模型应为 $x_u + \sum_{v \in N(u)} x_v \ge 1$。选项 D 使用了 $\le 1$，这表示每个顶点至多有一个邻居被选，完全改变了问题的含义。正确的 ILP 建模是：
- 变量：$x_u \in \{0,1\}$
- 目标：$\min \sum_{u \in V} x_u$（最小化支配集大小）
- 约束：$x_u + \sum_{v \in N(u)} x_v \ge 1$ 对所有 $u \in V$
- 含义：每个顶点 $u$ 要么自己被选（$x_u = 1$），要么至少一个邻居 $v$ 被选（$\sum_{v \in N(u)} x_v \ge 1$）

注意独立集和支配集约束的方向区别：独立集是"边两端不能同时选"（$\le 1$），支配集是"每个顶点必须被覆盖"（$\ge 1$）。

**4.（Simplex Method Properties, Slide09）** 关于单纯形法 (Simplex Method)，以下说法中选 **FALSE**：

- (A) 单纯形法每次迭代从一个顶点移动到另一个相邻顶点，目标函数值不降（对 max 问题）
- (B) 单纯形法在最坏情况下的时间复杂度是指数级的
- (C) 单纯形法不需要转换为松弛形式 (Slack Form)，可以直接在标准形式 (Standard Form) 上运行
- (D) 单纯形法的终止条件是所有非基变量在目标函数中的系数均为非正数

**答案**：C **解析**：

本题要求选出 **FALSE** 说法。对每一选项逐一分析：

**选项 (A) 正确**。单纯形法从一个初始顶点开始，每次沿可行多面体的边移动到相邻顶点，且对 max 问题目标函数值单调不降（严格意义上是不降，对于非退化情况则是严格递增）。这是因为每次 pivot 选择入基变量的标准就是它在目标函数中的系数为正，入基后目标函数值一定增大（或至少不降）。

**选项 (B) 正确**。虽然单纯形法在实际应用中效率极高（通常 $O(m+n)$ 次迭代即可收敛），但最坏情况下它的确是指数时间的。经典的反例是 Klee-Minty 立方体：构造一个 $n$ 维扭曲超立方体，单纯形法需要遍历几乎所有 $2^n$ 个顶点才能找到最优解。不过需要注意，这一指数行为是"路径选择"问题——若每次都选择改善最大的方向（最陡上升）可以避免，但最常用的 Bland 规则在某些构造下仍是指数的。

**选项 (C) 错误—本题答案**。单纯形法不能直接在 Standard Form（标准型：$\max c^T x$ s.t. $Ax \le b, x \ge 0$）上运行，因为标准型的约束都是不等式，没有可以直接用于表达基本可行解的等式结构。运行单纯形法的前提是将其转换为 Slack Form（松弛型），具体步骤是：
1. 对每个 $\le$ 约束引入松弛变量 $s_i \ge 0$
2. 将不等式转换为等式：$\sum a_{ij}x_j + s_i = b_i$
3. 得到等式约束后，区分非基变量（nonbasic）和基变量（basic）
4. 令非基变量为 0 得到基本可行解（basic feasible solution）
5. 然后才能执行 pivot 操作（交换非基变量和基变量）

因此选项 C 说"不需要 Slack Form"是错误的。

**选项 (D) 正确**。当 Slack Form 中目标函数的所有非基变量系数都 $\le 0$ 时，当前基本可行解就是最优解。因为目标函数形如 $z = v + \sum_{j \in N} c_j x_j$（其中 $N$ 是非基变量集），若所有 $c_j \le 0$，则任何增大非基变量的操作（从 0 变为正数）都会降低目标函数值（因为系数为负），因此当前解是最优的。

### 1. 线性规划的对偶理论与单纯形法（15 分）

#### （1）对偶转换（Duality Conversion, Slide09）（5'）

将以下线性规划问题转换为 Dual 问题：

```
min  z = 4x₁ + 3x₂
s.t. x₁ + 2x₂ = 10
     3x₁ + x₂ ≥ 15
     x₁ ≥ 0, x₂ 无限制 (unrestricted)
```

**答案**：

使用对偶转换规则表（min → max）：

| Primal (min) | Dual (max) |
|---|---|
| min | max |
| = 约束 | 对应变量无限制 |
| ≥ 约束 | 对应变量 **≥ 0** |
| ≤ 约束 | 对应变量 **≤ 0** |
| 变量无限制 | 对应约束为 = |
| 变量 ≥ 0 | 对应约束为 ≤ |
| 变量 ≤ 0 | 对应约束为 ≥ |

这个表可以从标准对偶对导出。标准 min primal 形式为 $\min c^T x$ s.t. $Ax \ge b, x \ge 0$，其对偶是 $\max b^T y$ s.t. $A^T y \le c, y \ge 0$。由此推导：
- min → max
- $\ge$ 约束 → $y \ge 0$（方向相同）
- $x \ge 0$ → 约束为 $\le$（方向相反）
- 等号约束和不限制变量可通过对偶对推导得出

转换结果：

```
max  w = 10y₁ + 15y₂
s.t. y₁ + 3y₂ ≥ 4       （对应 x₁ ≥ 0）
     2y₁ + y₂ = 3       （对应 x₂ 无限制）
     y₁ unrestricted, y₂ ≥ 0
```

#### （2）弱对偶定理证明（Weak Duality Theorem, Slide09）（5'）

证明弱对偶定理：若 x 是 primal (max) 的可行解，y 是 dual (min) 的可行解，则 c^T x ≤ b^T y。

**答案**：

**证明**：

设 primal 问题为：max c^T x  s.t. Ax ≤ b, x ≥ 0
dual 问题为：min b^T y  s.t. A^T y ≥ c, y ≥ 0

由于 y ≥ 0，将 primal 约束 Ax ≤ b 左乘 y^T：
y^T A x ≤ y^T b = b^T y

由于 x ≥ 0，将 dual 约束 A^T y ≥ c 左乘 x^T：
x^T A^T y ≥ x^T c = c^T x
即 y^T A x ≥ c^T x

联立：c^T x ≤ y^T A x ≤ b^T y

因此 c^T x ≤ b^T y，证毕。

**推论**：
- 若 primal 无界（c^T x → +∞），则 dual 不可行
- 若 dual 无界（b^T y → -∞），则 primal 不可行
- 若 c^T x = b^T y，则 x 和 y 分别是 primal 和 dual 的最优解（强对偶定理）

#### （3）整数线性规划建模（ILP Modeling, Slide09）（5'）

考虑一个无向图 $G = (V, E)$，其中 $V = \{1, 2, \dots, n\}$。

**（a）** 用 0-1 变量 $x_u$（$x_u = 1$ 表示顶点 $u$ 被选中）给出**最大独立集（Maximum Independent Set）** 问题的 ILP 建模，并解释每个约束的含义。

**（b）** 用 0-1 变量 $x_u$ 给出**最小支配集（Minimum Dominating Set）** 问题的 ILP 建模，并解释与最大独立集 ILP 的约束有何本质区别。

**答案**：

**（a）最大独立集（Maximum Independent Set）**

最大独立集要求选中的顶点之间没有边相连，目标是最大化选中顶点数。

```
max  Σ_{u∈V} x_u
s.t. x_u + x_v ≤ 1,  ∀ (u, v) ∈ E     （相邻顶点不能同时被选）
     x_u ∈ {0, 1},   ∀ u ∈ V
```

**约束解释**：对每条边 $(u, v)$，至多一个端点被选入独立集。若 $x_u = 1$ 则 $x_v$ 必须为 0，反之亦然。

**（b）最小支配集（Minimum Dominating Set）**

支配集要求每个顶点要么自身被选，要么至少有一个邻居被选，目标是最小化选中顶点数。

```
min  Σ_{u∈V} x_u
s.t. x_u + Σ_{v∈N(u)} x_v ≥ 1,  ∀ u ∈ V     （每个顶点自身或至少一个邻居被选）
     x_u ∈ {0, 1},              ∀ u ∈ V
```

其中 $N(u)$ 表示 $u$ 的邻接顶点集合。

**本质区别**：
- 独立集约束是 **≤ 1**（排斥关系：相邻顶点互斥）
- 支配集约束是 **≥ 1**（覆盖关系：每个顶点必须被覆盖）
- 独立集限制的是**边两端**的关系，支配集限制的是**每个顶点及其邻域**的关系
- 独立集是 max 问题，支配集是 min 问题

**附加说明**：独立集与顶点覆盖（Vertex Cover）互为对偶：顶点覆盖要求每条边至少有一个端点被选，ILP 为 min Σxᵤ s.t. xᵤ + xᵥ ≥ 1。有趣的是，独立集 ILP 的约束矩阵转置后恰好对应顶点覆盖的 ILP 松弛的约束。

### 2. 单纯形法迭代与顶点覆盖 ILP（15 分）

#### （1）单纯形法完整迭代（Simplex Iteration, Slide09）（6'）

考虑以下线性规划问题：

```
max  z = 3x₁ + 5x₂
s.t. x₁ + x₂ ≤ 4
     x₁ ≤ 2
     x₂ ≤ 3
     x₁, x₂ ≥ 0
```

（a）转换为 Slack Form，写出初始基本可行解。（2'）
（b）执行完整的两轮 Pivot 操作，直到所有目标函数系数非正，写出每轮入基/出基变量选择和新的基本可行解。（4'）

**答案**：

（a）Slack Form：

```
max  z = 3x₁ + 5x₂
s.t. x₁ + x₂ + x₃ = 4
     x₁ + x₄ = 2
     x₂ + x₅ = 3
     x₁, x₂, x₃, x₄, x₅ ≥ 0
```

非基变量：x₁, x₂；基变量：x₃, x₄, x₅
初始基本可行解：(0, 0, 4, 2, 3)，z = 0

（b）第 1 轮：选择 x₂ 入基（系数 5 > 3），最紧约束来自 x₅（x₂ ≤ 3），x₅ 出基。

Pivot 后：

```
max  z = 3x₁ + 5(3 - x₅) = 15 + 3x₁ - 5x₅
s.t. x₁ + (3 - x₅) + x₃ = 4 → x₁ + x₃ - x₅ = 1 → x₃ = 1 - x₁ + x₅
     x₁ + x₄ = 2 → x₄ = 2 - x₁
     x₂ = 3 - x₅
```

整理：

```
max  z = 15 + 3x₁ - 5x₅
s.t. x₃ = 1 - x₁ + x₅
     x₄ = 2 - x₁
     x₂ = 3 - x₅
     x₁, x₂, x₃, x₄, x₅ ≥ 0
```

非基变量：x₁, x₅；基变量：x₂, x₃, x₄
基本可行解：(0, 3, 1, 2, 0)，z = 15

第 2 轮：x₁ 系数为正 (3)，选择 x₁ 入基。最紧约束来自 x₃（x₁ ≤ 1），x₃ 出基。

Pivot 后：

```
max  z = 15 + 3(1 - x₃ + x₅) - 5x₅ = 18 - 3x₃ - 2x₅
s.t. x₁ = 1 - x₃ + x₅
     x₄ = 2 - (1 - x₃ + x₅) = 1 + x₃ - x₅
     x₂ = 3 - x₅
```

整理：

```
max  z = 18 - 3x₃ - 2x₅
s.t. x₁ = 1 - x₃ + x₅
     x₄ = 1 + x₃ - x₅
     x₂ = 3 - x₅
     x₁, x₂, x₃, x₄, x₅ ≥ 0
```

所有目标函数系数为负，终止。
非基变量：x₃, x₅；基变量：x₁, x₂, x₄
最优解：(x₁, x₂) = (1, 3)，最优值 z = 18

#### （2）顶点覆盖 ILP 建模（Vertex Cover ILP, Slide09）（5'）

最小顶点覆盖问题（Minimum Vertex Cover）：给定无向图 G = (V, E)，求一个最小的顶点子集 S ⊆ V，使得每条边至少有一个端点在 S 中。

（a）用 0-1 变量 xᵤ 给出该问题的 ILP 建模。（2'）
（b）证明：若 x 是独立集 ILP 的可行解，则 1 - x（即对每个分量取补）是顶点覆盖 ILP 的可行解。这说明了独立集与顶点覆盖之间的什么关系？（3'）

**答案**：

（a）ILP 建模：

```
min  Σ_{u∈V} xᵤ
s.t. xᵤ + xᵥ ≥ 1,  ∀ (u, v) ∈ E
     xᵤ ∈ {0, 1},   ∀ u ∈ V
```

约束含义：每条边至少有一个端点被选中。

（b）证明：

设 x 是独立集的可行解，即 xᵤ + xᵥ ≤ 1 对所有 (u,v)∈E 成立，且 xᵤ ∈ {0,1}。
定义 yᵤ = 1 - xᵤ，则 yᵤ ∈ {0,1}。
对任意边 (u,v)∈E：

yᵤ + yᵥ = (1 - xᵤ) + (1 - xᵥ) = 2 - (xᵤ + xᵥ) ≥ 2 - 1 = 1

因此 y 满足顶点覆盖的所有约束，是顶点覆盖的可行解。

**关系**：独立集和顶点覆盖互为补集关系。S 是独立集当且仅当 V\S 是顶点覆盖。
- 若 S 是独立集，则每条边至多一个端点在 S 中，即每条边至少一个端点在 V\S 中，故 V\S 是顶点覆盖。
- 反之亦然。

因此 |S| + |V\S| = |V|，最大化独立集等价于最小化顶点覆盖（在一般图中计算复杂度不同，但在二部图中可通过 König 定理建立等价关系）。

#### （3）强对偶定理的应用（Strong Duality Application, Slide09）（4'）

已知某工厂生产问题的 Primal LP 的最优解为 x* = (100, 300)，最优值 z* = 1900。其 Dual 问题为：

```
min  400y₁ + 200y₂ + 300y₃
s.t. y₁ + y₂ ≥ 1
     y₁ + y₃ ≥ 6
     y₁, y₂, y₃ ≥ 0
```

（a）验证 y = (1, 0, 5) 是 Dual 的可行解，且目标函数值为 1900。（2'）
（b）根据强对偶定理，这说明什么？并解释 y₂ = 0 的经济含义（即对应资源是"充裕"的，影子价格为 0）。（2'）

**答案**：

（a）验证：
- y₁ + y₂ = 1 + 0 = 1 ≥ 1 ✓
- y₁ + y₃ = 1 + 5 = 6 ≥ 6 ✓
- y₁, y₂, y₃ ≥ 0 ✓
所以 y = (1,0,5) 是 Dual 的可行解。
目标值：400×1 + 200×0 + 300×5 = 400 + 1500 = 1900 = z*

（b）由强对偶定理，x* 和 y 分别是 Primal 和 Dual 的最优解（因为可行解目标值相等）。

y₂ = 0 的经济含义：资源 2（对应约束 x₁ ≤ 200，即产品 1 的原料 A）在当前最优解下是充裕的。最优解 x₁ = 100，而资源 2 上限为 200，还有 100 单位的闲置。因此增加资源 2 的供应不会提高利润，其"影子价格"为 0。相反，y₁ = 1 和 y₃ = 5 对应的资源 1 和资源 3 是稀缺的，每增加一单位可分别带来 1 和 5 的边际利润。
