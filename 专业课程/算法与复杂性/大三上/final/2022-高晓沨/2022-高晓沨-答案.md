## Part 1. Multiple Choice Questions (3.5' × 10 = 35')

**问题 1**

* **答案**：$O(n \log n)$
* **解析**：外层循环 $i$ 从 $1$ 遍历到 $n$，内层循环 $j$ 从 $1$ 遍历到 $\lfloor n/i \rfloor$。因此，内层循环的执行次数为 $\lfloor n/i \rfloor$。整个算法的总执行次数可以表示为：
$$ \sum_{i=1}^{n} \lfloor n/i \rfloor \le \sum_{i=1}^{n} \frac{n}{i} = n \sum_{i=1}^{n} \frac{1}{i} $$
由于调和级数 $\sum_{i=1}^{n} \frac{1}{i} = \ln n + O(1) = O(\log n)$，所以总时间复杂度为 $O(n \log n)$。

**问题 2**

* **答案**：Merge Sort
* **解析**：题目要求选择“最稳定的排序算法”，并进一步解释为“在最坏情况下具有最佳时间复杂度的稳定排序算法”（stablest... i.e., finding the sorting algorithm that has the best time complexity under the worst case）。
* 快速排序（Quick Sort）最坏情况下时间复杂度为 $O(n^2)$ 且不稳定。
* 冒泡排序（Bubble Sort）和插入排序（Insertion Sort）最坏情况下时间复杂度均为 $O(n^2)$。
* 归并排序（Merge Sort）在最坏情况下的时间复杂度为 $O(n \log n)$，且它是一种稳定的排序算法。因此，归并排序在最坏情况下具有最佳的时间复杂度。



**问题 3**

* **答案**：Graphic Matroid - Kruskal Algorithm
* **解析**：
* 图拟阵（Graphic Matroid）的独立集定义为无向图中的无环边集（即森林）。在该拟阵上应用贪心算法（Greedy-MAX）来寻找最大权重独立集，对应的正是求解最大/最小生成树的克鲁斯卡尔算法（Kruskal Algorithm）。
* 普里姆算法（Prim Algorithm）虽然也是贪心策略，但它的工作机制不直接对应于图拟阵的标准贪心扩展机制（它基于顶点逐步扩展，而不是在整个拟阵边集上按权重排序进行贪心选择）。
* 割拟阵（Cographic Matroid）对应的贪心算法通常用于求解其他问题，而非标准的 Kruskal 算法。



**问题 4**

**问题 5**

* **答案**："If $N>M$ we have $R_{N}=\max_{1\le i<N}\{R_{i}+R_{N-M}\}$" is FALSE.
* **解析**：该递推式的错误在于当 $N > M$（钢条长度大于价格表的最大长度 $M$）时，强行在右侧项减去固定值 $M$，这在数学和逻辑上是错误的，无法涵盖所有可能的切分情况。
  * 当钢条长度 $N > M$ 时，第一段切下来的长度 $i$（其中 $1 \le i < N$）不能超过 $M$，因为价格表只定义到长度 $M$。但剩余部分 $N-i$ 仍可能大于 $M$。
  * 正确的状态转移方程依然需要枚举第一段切下来的长度 $i$（其中 $1 \le i \le \min(N, M)$），使用价格 $P_i$，并对剩余部分递归：$R_N = \max_{1 \le i \le \min(N, M)} \{P_i + R_{N-i}\}$。
  * 选项中 $R_{N}=\max_{1\le i<N}\{R_{i}+R_{N-M}\}$ 的错误在于：第一段用了 $R_i$（本应是价格 $P_i$），且第二段减去固定值 $M$ 而非 $i$。

**问题 10**

* **答案**：$O(1), O(\log n), O(n)$
* **解析**：
* **最好情况（Best case）**：当最小的栈 $S_0$ 未满时，直接入栈，耗时 $O(1)$。
* **最坏情况（Worst case）**：当执行 push 操作时，触发了连续的满栈迁移，需要把前面所有栈的所有元素（共 $n$ 个元素）全部弹出并移动到下一个栈中。因为总元素量为 $n$，所以最坏情况下的操作代价为 $O(n)$。
* **平均/摊还情况（Average/Amortized case）**：分析连续 \(m\) 次 push 操作的总耗时：对于第 \(i\) 个栈 \(S_i\)，其容量为 \(3^i\)。每当它存满时，需要将 \(3^i\) 个元素全部移动到 \(S_{i+1}\)，该移动操作消耗的时间与元素数量成正比，即 \(3^i\)。在连续 \(m\) 次 push 中，\(S_i\) 会发生满载的次数大约为 \(\frac{m}{3^i}\) 次。因此，处理 \(S_i\) 中元素移动所消耗的总时间为：\(\frac{m}{3^i} \times 3^i = m\)。栈的级别 \(i\) 可以取 \(0, 1, \dots, \log_3 m\)，所以 \(m\) 次操作的总耗时为：\[
 \sum_{i=0}^{\log_3 m} m = m \cdot (\log_3 m + 1) 
\]将总耗时均摊到单次 push 操作上，均摊时间复杂度为 \(O(\log m)\)。由于 \(m\) 即为栈中的元素数量 \(n\)，所以均摊时间复杂度为 **\(O(\log n)\)**。

**结论：**
*   **最好情况：** \(O(1)\)
*   **最坏情况：** \(O(n)\)
*   **平均/均摊情况：** \(O(\log n)\)

### QA1: Divide-and-Conquer (15')

#### (a) Master's Theorem (5')

设递推关系为 $T(n) = aT(n/b) + f(n)$，其中 $a \ge 1$, $b > 1$ 为常数，$f(n)$ 为渐近正函数。

比较 $f(n)$ 与 $n^{\log_b a}$：

1. **Case 1**: 若 $f(n) = O(n^{\log_b a - \varepsilon})$ 对某 $\varepsilon > 0$ 成立，则 $T(n) = \Theta(n^{\log_b a})$
2. **Case 2**: 若 $f(n) = \Theta(n^{\log_b a} \log^k n)$ 对某 $k \ge 0$ 成立，则 $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$
3. **Case 3**: 若 $f(n) = \Omega(n^{\log_b a + \varepsilon})$ 对某 $\varepsilon > 0$ 成立，且**正则条件** $af(n/b) \le cf(n)$ 对某 $c < 1$ 和足够大的 $n$ 成立，则 $T(n) = \Theta(f(n))$

#### (b) Recurrence Analysis (5')

**无法从 PDF 文本读取具体的递推式**。通用分析框架：

1. 检查是否符合 Master Theorem 形式 $T(n) = aT(n/b) + f(n)$
2. 计算 $n^{\log_b a}$，比较 $f(n)$ 的阶
3. 若 $f(n)$ 不是多项式可比的（如 $f(n) = n^{\log_b a} \log n$ 属于 Case 2），或 $a$ 非常数，则不能直接用 Master Theorem
4. 不能用时，采用**递归树法**或**代入法**

#### (c) Perfect Permutation (5')

这个问题要求我们生成一个长度为 $n$ 的**完美排列**（Perfect Permutation），其核心条件是：不存在任何三个位置的元素满足 $2\Pi_k = \Pi_i + \Pi_j$（且 $i < k < j$）。这意味着排列中**不包含长度为 3 的等差数列（Arithmetic Progression, AP）**。

在组合数学中，这与经典的 **分治法（Divide and Conquer）** 生成无等差数列排列的算法高度相关。

**算法思路与数学原理**

我们可以通过分治的思想来构造这个排列：

1. **奇偶分离**：将当前集合中的元素分为**奇数**和**偶数**两部分。
2. **性质保障**：如果我们把所有奇数放在左边，所有偶数放在右边。那么，任何跨越两部分的三个数（$i$ 在左，$j$ 在右），它们的和 $\Pi_i + \Pi_j$ 必然是一个“奇数 + 偶数 = 奇数”。而 $2\Pi_k$ 必然是一个偶数。因此，**跨越左右两部分的三个数绝对不可能组成等差数列**。
3. **递归求解**：接下来，我们只需要分别确保左半部分的奇数之间、以及右半部分的偶数之间没有等差数列即可。
4. **等价映射**：
* 奇数序列可以写成 $2x - 1$ 的形式。
* 偶数序列可以写成 $2x$ 的形式。
* 注意到，如果序列 $x_1, x_2, \ldots$ 中没有等差数列，那么经过线性变换 $2x-1$ 或 $2x$ 之后的新序列也绝对不会包含等差数列。因此，我们可以将规模为 $n$ 的问题递归地转化为规模为 $\lceil n/2 \rceil$ 和 $\lfloor n/2 \rfloor$ 的子问题。

**伪代码实现 (Pseudo-code)**

以下是用分治法生成完美排列的伪代码：

```text
Algorithm: GeneratePerfectPermutation(n)
Input: 一个正整数 n
Output: 一个包含 1 到 n 的完美排列数组 Pi

1. If n == 1 Then
2.     Return [1]
3. EndIf

// 递归获取规模为 ceil(n/2) 和 floor(n/2) 的基础排列
4. left_size = ceil(n / 2)
5. right_size = floor(n / 2)

6. L = GeneratePerfectPermutation(left_size)
7. R = GeneratePerfectPermutation(right_size)

8. Pi = Empty List or Array of size n
9. idx = 1

// 将左边的排列映射为 1 到 n 之间的奇数
10. For Each x In L Do
11.     Pi[idx] = 2 * x - 1
12.     idx = idx + 1
13. EndFor

// 将右边的排列映射为 1 到 n 之间的偶数
14. For Each x In R Do
15.     Pi[idx] = 2 * x
16.     idx = idx + 1
17. EndFor

18. Return Pi

```

**算法复杂度分析**

* **时间复杂度**：$O(n \log n)$。
每一层递归中，我们需要遍历并组合长度为 $n$ 的数组，耗时 $O(n)$。递归树的深度为 $\log n$。因此总时间复杂度为 $O(n \log n)$。如果有序地利用迭代自底向上构建，甚至可以优化到 $O(n)$。
* **空间复杂度**：$O(n \log n)$（由于递归调用的栈空间和临时数组），如果原地修改或自底向上迭代可以优化到 $O(n)$。

### QA2: Greedy Strategy & Dynamic Programming (18')

#### (a) Watch as Many TV Series as Possible — Activity Selection (9')

**问题**：给定 $n$ 个电视节目，每个有开始时间 $s_i$ 和结束时间 $e_i$，一台电视最多能看多少个完整的节目？

**算法**：贪心 — **最早结束时间优先 (Earliest Finish Time First)**

```
GREEDY-TV-SELECTION(S, E, n)
    // S[1..n]: 开始时间, E[1..n]: 结束时间
    将所有节目按结束时间 E[i] 升序排序
    selected = 0
    last_end = 0
    for i = 1 to n  // 已按结束时间排序
        if S[i] ≥ last_end
            selected += 1
            last_end = E[i]
    return selected
```

**正确性证明**（交换论证）：
- 设贪心解为 $G$，最优解为 $OPT$
- 考虑第一个节目：贪心选择结束时间最早的节目 $g_1$，$OPT$ 中第一个节目 $o_1$ 满足 $e_{g_1} \le e_{o_1}$
- 若 $o_1 \neq g_1$，用 $g_1$ 替换 $o_1$ 得到新解 $OPT'$ 仍然可行且大小不变
- 归纳可得贪心解即为最优

**复杂度**：
- 时间：$O(n \log n)$（排序）+ $O(n)$（遍历）= $O(n \log n)$
- 空间：$O(1)$（或 $O(n)$ 存储排序后数据）

#### (b) Maximize Happiness Within Time Limit — 0/1 Knapsack (9')

**问题**：给定 $n$ 个电视节目，时间总预算 $T$，每个节目有快乐值 $h_i$ 和时长 $t_i$，选择节目使总快乐值最大化。

**算法**：动态规划（0/1 背包）


```
DP-BACKPACK(h, t, n, T)
    dp[0..T] = 0
    for i = 1 to n:
        for j = T down to t[i]:
            dp[j] = max(dp[j], dp[j - t[i]] + h[i])
    return dp[T]
```

**复杂度**：
- 时间：$O(nT)$
- 空间：$O(T)$


**若考虑节目不能重叠**（加权区间调度 + 时间约束），则：
```
DP-TV-SCHEDULING(S, E, H, n, T)
    // 按结束时间 E[i] 升序排序
    将所有节目按 E[i] 升序排序

    // 预处理 p[i]
    for i = 1 to n
        p[i] = max{ j | j < i and E[j] ≤ S[i] }
        if 不存在, p[i] = 0

    // dp[i][t]：前 i 个节目，总时长不超过 t 的最大快乐值
    初始化 dp 为 (n+1) × (T+1) 的零矩阵

    for i = 1 to n
        dur_i = E[i] - S[i]
        for t = 0 to T
            // 不选 i
            dp[i][t] = dp[i-1][t]
            // 选 i（如果时长允许）
            if t >= dur_i:
                dp[i][t] = max(dp[i][t], H[i] + dp[p[i]][t - dur_i])

    return dp[n][T]
```

**复杂度**：
- 时间：$O(n\log n)$（排序）+ $O(n\log n)$（二分查找 $p[i]$）+ $O(nT)$（循环）= $O(n\log n + nT)$
- 空间：$O(nT)$

### QA3: Network Flow (17')

#### (a) Edge-Disjoint Paths from Multiple Sources to Sinks (8')

**问题**：给定连通有向图 $G=(V,E)$，源集 $S=\{s_1,\dots,s_m\}$ 和汇集 $T=\{t_1,\dots,t_k\}$，找尽可能多的路径，使：
1. 每条路径从某个 $s_i$ 出发到某个 $t_j$
2. 路径之间**边不相交**
3. 不同路径**终点**不同（每个 $t_j$ 最多被一条路径使用）

**算法**：归约为最大流问题

```
EDGE-DISJOINT-PATHS(G, S, T)
    // 1. 构建流网络 G' = (V', E')
    // 添加超级源点 s* 和超级汇点 t*
    // s* 到每个 s_i 连容量为 1 的边
    // 每个 t_j 到 t* 连容量为 1 的边 (保证每终点只用一次)
    // 原图每条边容量设为 1 (保证边不相交)
    
    // 2. 求最大流
    在 G' 上运行 Ford-Fulkerson 或 Dinic
    
    // 3. 提取路径
    f = 最大流值
    从 s* 到 t* 的流量即找到的路径数
    可通过反向边回溯具体路径
    
    return f 条边不相交路径
```

**正确性**：
- 每条边容量为 1 → 每条边最多被一条路径使用 → 边不相交
- $s^* \to s_i$ 容量为 1 → 每个源点最多发出一条路径
- $t_j \to t^*$ 容量为 1 → 每个汇点最多接收一条路径

**复杂度**：$O(|V| \cdot |E|^2)$（Dinic: $O(\sqrt{|V|} \cdot |E|)$）

#### (b) Vertex-Disjoint + Edge-Disjoint Paths (9')

**问题**：在 (a) 的基础上，额外要求路径之间**顶点也不相交**（起点终点除外）。

**算法**：**顶点分裂 (Vertex Splitting)**

```
VERTEX-DISJOINT-PATHS(G, S, T)
    // 1. 顶点分裂构建 G'
    对每个顶点 v ∈ V \ (S ∪ T):
        将 v 分裂为 v_in 和 v_out
        连边 v_in → v_out, 容量为 1 (顶点容量限制)
        原入边改为进入 v_in
        原出边改为从 v_out 出发
    
    对于原图中的每条有向边，在流网络中将其连接为从源点的出节点到目标点的入节点，其容量设为 1。
    
    // 2. 加超级源汇
    s* 到每个 s_i_in 连容量为 1 的边
    每个 t_j_in 到 t* 连容量为 1 的边
    
    // 3. 原图普通边 (分裂后从 u_out 到 v_in)
    容量设为 1 (保证边不相交)
    
    // 4. 求最大流
    return 最大流值及具体路径
```

**关键点**：
- 顶点内部边容量 1 → 每个中间顶点最多被一条路径经过 → 顶点不相交
- 原图边容量 1 → 仍然边不相交
- 源汇点容量 ∞ → 允许多路径以不同源点出发、不同汇点结束

**复杂度**：$O(|V|^2 \cdot |E|)$（Dinic 在分裂图上）

### QA4: NP and Polynomial-Time Reduction (15')

#### (a) Certificate and Certifier for PARTITION (5')

**PARTITION 问题**：给定 $n$ 个非负整数 $a_1,\dots,a_n$，是否存在子集 $X \subseteq \{1,\dots,n\}$ 使得 $\sum_{i\in X} a_i = \sum_{i\notin X} a_i$？

**Certificate（证书）**：一个子集 $X \subseteq \{1,\dots,n\}$（或其指示向量 $x \in \{0,1\}^n$）。

**Certifier（验证器）**：
```
CERTIFY-PARTITION(a, n, X)
    sum_X = 0
    sum_total = 0
    for i = 1 to n:
        sum_total += a_i
        if i ∈ X:
            sum_X += a_i
    return (sum_X * 2 == sum_total)
```

**NP 证明**：
1. 证书 $X$ 的大小为 $O(n)$（多项式于输入规模 $n$）
2. 验证过程只需 $O(n)$ 时间（多项式时间）
3. 若答案为 YES，存在证书使验证器接受
4. 若答案为 NO，对任何证书验证器都拒绝
5. 因此 PARTITION ∈ NP

#### (b) PARTITION is NP-complete (5')

**证明思路**：SUBSET-SUM $\le_p$ PARTITION

**SUBSET-SUM 问题**：给定 $n$ 个非负整数 $b_1,\dots,b_n$ 和整数 $t$，是否存在子集 $Y$ 使 $\sum_{i\in Y} b_i = t$？

**归约构造**：
给定 SUBSET-SUM 实例 $(b_1,\dots,b_n,t)$，设 $S = \sum_{i=1}^n b_i$。

构造 PARTITION 实例 $(a_1,\dots,a_n, a_{n+1})$：
- $a_i = b_i$ 对 $i = 1,\dots,n$
- $a_{n+1} = |S - 2t|$（添加一个新的数）

**正确性**：
- $(\Rightarrow)$ 若 SUBSET-SUM 有解 $Y$，则 $\sum_{i\in Y} b_i = t$
  - 若 $S - 2t \ge 0$：将 $Y \cup \{n+1\}$ 作为 PARTITION 的解，验证 $\sum_{Y} + (S-2t) = t + S - 2t = S - t = \sum_{\overline{Y}}$
  - 若 $S - 2t < 0$：将 $Y$ 作为 PARTITION 的解，验证 $\sum_{Y} = t = (2t-S) + (S-t) = (2t-S) + \sum_{\overline{Y}}$
  
- $(\Leftarrow)$ 若 PARTITION 有解 $X$，则根据 $n+1$ 在 $X$ 中的归属，可构造 SUBSET-SUM 的解

**结论**：SUBSET-SUM 是已知的 NP-complete 问题（已证明），故 PARTITION ∈ NP-complete。

#### (c) Even-Sized Partition — Still NP-complete? (5')

**问题**：$n$ 为偶数，且要求 $|X| = n/2$（子集恰含一半元素）。PARTITION 在此约束下是否仍为 NP-complete？

**答案：是，仍然是 NP-complete。**

**证明**：从原 PARTITION 问题归约。

设原 PARTITION 实例为 $A = \{a_1,\dots,a_n\}$，总和为 $M$。

若 $n$ 已经是偶数，我们可以用如下方法添加约束：

构造新实例 $A' = \{a_1,\dots,a_n, \underbrace{0,0,\dots,0}_{n\text{ 个}}\}$，共 $2n$ 个元素（偶数）。
- 若原 PARTITION 有解 $X$，则 $X' = X \cup (\text{适当数量的 }0)$ 可使 $|X'| = n$ 且和为 $M/2$
- 反之，若 $A'$ 有大小为 $n$ 的子集和为 $M/2$，去掉其中的 0 即得原问题的解
