## 一、平面点集极小点（15 分）

给定平面上的 $n$ 个点 $(x_i, y_i)$。一个点 $(x_i, y_i)$ 被称为**极小点**，如果不存在另一个点 $(x_j, y_j)$ 满足 $x_j \le x_i$ 且 $y_j \le y_i$ 且至少一个不等式严格成立（即 $(x_i, y_i)$ 不被任何其他点"支配"）。

设计算法找出给定点集中的所有极小点，并分析时间复杂度。

---

**参考答案：**

**算法思路：** 极小点即 Pareto 前沿面（非支配点集）。将点按 $x$ 坐标升序排序，然后从左到右扫描，维护当前已扫描点的最小 $y$ 值。若当前点的 $y$ 小于已见过的最小 $y$，则该点为极小点。

**伪代码：**
```
Algorithm FindMinimalPoints(P[1..n])
    // P[i] = (x_i, y_i)
    Sort P by x ascending (若 x 相同，按 y 升序)
    minimal ← []
    min_y ← +∞
    for i ← 1 to n do
        if P[i].y < min_y then
            minimal ← minimal ∪ {P[i]}
            min_y ← P[i].y
    return minimal
```

**正确性：** 排序后 $x$ 从左到右递增。扫描时若遇到比之前所有点 $y$ 都更小的点，则它不可能被之前的点支配（之前点 $x$ 更小但 $y$ 更大），也不可能被之后的点支配（之后点 $x$ 更大）。反之，若某点的 $y$ 不小于之前某个点的 $y$，则它被那个点支配。

**时间复杂度：** 排序 $O(n \log n)$，扫描 $O(n)$，总时间 $O(n \log n)$。

**空间复杂度：** $O(n)$（存储结果）。

## 二、数组峰值查找（15 分）

给定一个长度为 $n$ 的数组 $A[1..n]$，已知数组**先严格上升后严格下降**（即存在唯一峰值下标 $p$，满足 $A[1] < A[2] < \dots < A[p] > A[p+1] > \dots > A[n]$，且 $A[p]$ 是数组的最大值）。边界情况包括：
- 若数组严格递增（无下降部分），则 $p = n$
- 若数组严格递减（无上升部分），则 $p = 1$

设计算法找出峰值下标 $p$，并分析时间复杂度。

---

**参考答案：**

**算法思路：** 变体二分查找。比较 $A[mid]$ 和 $A[mid+1]$，判断峰值在左侧还是右侧。

**伪代码：**
```
Algorithm FindPeak(A[1..n])
    left ← 1, right ← n
    while left < right do
        mid ← ⌊(left + right) / 2⌋
        if A[mid] < A[mid + 1] then
            // 上升趋势，峰值在右侧
            left ← mid + 1
        else
            // 下降趋势（含相等），峰值在左侧（含 mid）
            right ← mid
    return left  // left = right = p
```

**正确性分析：**
- 若 $A[mid] < A[mid+1]$，说明 $mid$ 处于上升段，峰值一定在 $mid$ 右侧（$mid$ 不可能是峰值），故 $left \leftarrow mid+1$
- 若 $A[mid] > A[mid+1]$，说明 $mid$ 处于下降段或正好是峰值，峰值在 $mid$ 或左侧，故 $right \leftarrow mid$
- 当 $left = right$ 时即为峰值位置

**边界情况：**
- 严格递增数组（$p = n$）：最终 $left$ 会收敛到 $n$
- 严格递减数组（$p = 1$）：最终 $left$ 会收敛到 $1$

**时间复杂度：** $O(\log n)$，每次迭代减半搜索范围。空间复杂度 $O(1)$。

## 三、杨氏矩阵（15 分）

**杨氏矩阵（Young Tableau）** 是一个 $m \times n$ 的矩阵，每行从左到右递增，每列从上到下递增。例如：

$$
\begin{bmatrix}
1 & 3 & 5 \\
2 & 4 & 7 \\
6 & 8 & 9
\end{bmatrix}
$$

**(a)** (4 分) 设计 $O(m + n)$ 算法删除矩阵中的最小元素（删除后矩阵左上角空缺，需调整维持杨氏矩阵性质）。

**(b)** (4 分) 设计 $O(m + n)$ 算法在矩阵中插入一个新元素。

**(c)** (4 分) 利用杨氏矩阵设计 $O(n^3)$ 算法对 $n^2$ 个元素进行排序（假设 $m = n$）。

**(d)** (3 分) 设计 $O(m + n)$ 算法在杨氏矩阵中查找是否存在给定值 $x$。

---

**参考答案：**

**(a)** 删除最小元素（即左上角 $Y[1][1]$）：

```
Algorithm YoungDeleteMin(Y[1..m][1..n])
    // 将右下角元素移至左上角（或标记为 ∞）
    Y[1][1] ← ∞
    i ← 1, j ← 1
    while i < m or j < n do
        // 找到右和下中较小的值
        if j = n or (i < m and Y[i+1][j] ≤ Y[i][j+1]) then
            // 与下方交换
            swap(Y[i][j], Y[i+1][j])
            i ← i + 1
        else
            // 与右方交换
            swap(Y[i][j], Y[i][j+1])
            j ← j + 1
    // 此时 ∞ 沉到了右下角，可将其视为已删除
```

**复杂度：** 每次迭代 $i$ 或 $j$ 增加 1，最多 $m + n$ 步，$O(m + n)$。

**(b)** 插入新元素：

```
Algorithm YoungInsert(Y[1..m][1..n], x)
    // 将 x 放入右下角
    Y[m][n] ← x
    i ← m, j ← n
    while i > 1 or j > 1 do
        // 找到左和上中较大的值
        if j = 1 or (i > 1 and Y[i-1][j] ≥ Y[i][j-1]) then
            if Y[i][j] < Y[i-1][j] then
                swap(Y[i][j], Y[i-1][j])
                i ← i - 1
            else break
        else
            if Y[i][j] < Y[i][j-1] then
                swap(Y[i][j], Y[i][j-1])
                j ← j - 1
            else break
```

**复杂度：** 最多 $m + n$ 步，$O(m + n)$。

**(c)** 利用杨氏矩阵排序（$m = n$）：

```
Algorithm YoungSort(A[1..n^2])
    // 创建 n×n 杨氏矩阵
    Y ← 创建 n×n 矩阵，所有元素为 ∞
    // 逐个插入
    for each element x in A do
        YoungInsert(Y, x)
    // 逐个删除最小
    for i ← 1 to n^2 do
        A[i] ← YoungDeleteMin(Y)
    return A
```

**复杂度分析：**
- 每次插入 $O(n + n) = O(n)$，共 $n^2$ 次插入 → $O(n^3)$
- 每次删除 $O(n + n) = O(n)$，共 $n^2$ 次删除 → $O(n^3)$
- 总时间复杂度：$O(n^3)$

**注意：** 当 $m = n$ 时 $m + n = 2n$，$n^2 \times O(n) = O(n^3)$。

**(d)** 查找元素：

```
Algorithm YoungSearch(Y[1..m][1..n], x)
    i ← 1, j ← n          // 从右上角开始
    while i ≤ m and j ≥ 1 do
        if Y[i][j] = x then return (i, j)
        else if Y[i][j] > x then j ← j - 1   // 排除当前列
        else i ← i + 1                         // 排除当前行
    return "未找到"
```

**正确性：** 从右上角 $(1, n)$ 开始。若当前值 $> x$，则当前列下方所有值均 $> x$（列递增），可排除整列。若当前值 $< x$，则当前行左侧所有值均 $< x$（行递增），可排除整行。每次排除一行或一列，最多 $m + n$ 步。

**复杂度：** $O(m + n)$。

## 四、稠密无向图的完美匹配（15 分）

给定一个稠密无向图 $G = (V, E)$，$|V| = 2n$，每个顶点的度数至少为 $n$。设计算法寻找一个**完美匹配**（即 $n$ 条不相交的边覆盖所有顶点），并证明算法的正确性。

> 注：课上只提供了正确性证明，未提供伪代码。

---

1. **贪心初始化**：在图 $G$ 中随意选取一条边加入集合 $M$，并将其两个端点标记为已匹配。不断重复此过程寻找不相交的边，直到图中不存在两端都未匹配的边为止。此时 $M$ 是一个**极大匹配**（Maximal Matching）。如果此时 $|M| = n$，算法结束。
2. **寻找未匹配点**：如果 $|M| < n$，由于图中总共有 $2n$ 个顶点，且每条匹配边覆盖 2 个顶点，必然至少剩下两个未匹配的顶点。任取两个未匹配顶点，记为 $u$ 和 $v$。
3. **边替换（寻找增广路）**：遍历当前匹配 $M$ 中的每一条边 $e = (x, y)$，检查 $u, v$ 与端点 $x, y$ 之间的连边情况：
* 如果存在交叉连边，即 $(u, x) \in E$ 且 $(v, y) \in E$，则将边 $(x, y)$ 从 $M$ 中移除，并将边 $(u, x)$ 和 $(v, y)$ 加入 $M$。
* 如果存在另一种交叉连边，即 $(u, y) \in E$ 且 $(v, x) \in E$，同样将 $(x, y)$ 移除，加入 $(u, y)$ 和 $(v, x)$。


4. **循环迭代**：每次成功执行步骤 3 后，匹配集合 $M$ 的边数会严格增加 1。重复执行步骤 2 和步骤 3，直到 $|M| = n$，此时 $M$ 即为所求的完美匹配。


为了证明该算法的正确性，我们需要证明：**只要 $|M| < n$，步骤 3 中必然能找到一条符合条件的匹配边 $(x, y)$ 来完成替换，使得匹配数增加 1。**

首先，因为我们在步骤 1 中构造的是一个极大匹配，所以未匹配顶点之间绝对不可能存在边（否则在步骤 1 中这两点就会被连成一条边加入 $M$）。因此，未匹配顶点 $u$ 和 $v$ 的所有邻居必然全部在已匹配的顶点集合 $V(M)$ 中。

已知图中每个顶点的度数至少为 $n$，所以 $\deg(u) \ge n$ 且 $\deg(v) \ge n$。这意味着 $u$ 和 $v$ 到集合 $V(M)$ 的连边总数至少为 $2n$。

假设当前匹配的边数为 $|M| = k$（其中 $k < n$），那么已匹配的顶点数 $|V(M)| = 2k$。我们将 $u$ 和 $v$ 发出的连边，按照 $M$ 中的这 $k$ 条匹配边进行分组。

根据**鸽巢原理**（抽屉原理），将至少 $2n$ 条边分配给 $k$ 条匹配边，由于 $2n > 2k$，必然存在匹配 $M$ 中的某一条边 $e = (x, y)$，使得 $u$ 和 $v$ 到端点 $x, y$ 的连边总数**至少为 3**。

因为 $u$ 和 $v$ 到 $\{x, y\}$ 最多只能有 4 条边，连边数为 3 或 4 意味着：端点 $x$ 和 $y$ 中，必然有一个同时连接了 $u$ 和 $v$，而另一个至少连接了 $u$ 或 $v$ 中的一个。

不妨设端点 $x$ 同时连接了 $u$ 和 $v$（即 $(u, x) \in E$ 且 $(v, x) \in E$），而端点 $y$ 连接了 $u$（即 $(u, y) \in E$）。此时，我们在图中实际上找到了一条长度为 3 的增广路径：


$$v - x - y - u$$

我们将匹配 $M$ 中的边 $(x, y)$ 删去，替换为 $(v, x)$ 和 $(u, y)$。原本的 1 条匹配边变成了 2 条匹配边，没有任何冲突，$M$ 的大小成功增加了 1。

由于替换后，未匹配顶点的集合只是少了 $u$ 和 $v$，剩余的未匹配顶点之间依然不存在连边，极大匹配的性质（针对未匹配点构成的独立集）依然得以保持。算法可以无障碍地继续进行，每次扩充只需遍历最多 $O(n)$ 条边，最多扩充 $n$ 次。因此，算法必定会终止于 $|M| = n$，正确且高效地输出一个完美匹配。

## 五、快速排序与三路划分（20 分）

**(a)** (4 分) 给出常规快速排序中 `split`（划分）函数的伪代码（以数组最后一个元素为 pivot）。

**(b)** (4 分) 说明当数组中所有元素都相等时，常规快速排序的时间复杂度。

**(c)** (6 分) 修改 `split` 函数，使其返回两个下标 $q$ 和 $t$，将数组划分为三段：$A[1..q-1] < A[q]$，$A[q..t] = A[q]$，$A[t+1..n] > A[q]$。

**(d)** (6 分) 利用 (c) 中新的 `split` 函数写出新的快速排序算法。

---

**参考答案：**

**(a)** 常规划分（Lomuto 划分）：

```
Algorithm Split(A[1..n], low, high)
    // 选 A[high] 为 pivot
    pivot ← A[high]
    i ← low
    for j ← low to high - 1 do
        if A[j] ≤ pivot then
            swap(A[i], A[j])
            i ← i + 1
    swap(A[i], A[high])
    return i         // 返回 pivot 的最终位置
```

**(b)** 所有元素相等时的时间复杂度：

当所有元素相等时，Lomuto 划分中每个元素都满足 $A[j] \le pivot$，每次迭代 $i$ 都递增，最终 pivot 被交换到 $high$ 位置（即最后一个位置）。每次划分将数组分为大小为 $n-1$ 和 $0$ 的两部分。

递推式：$T(n) = T(n-1) + O(n) = O(n^2)$

同样，Hoare 划分也会退化，因为相等元素无法有效分割。

**(c)** 三路划分（Dutch National Flag 划分）：

```
Algorithm ThreeWaySplit(A[1..n], low, high)
    // 选 A[high] 为 pivot
    pivot ← A[high]
    lt ← low            // lt 指向 < 区的右边界+1
    gt ← high           // gt 指向 > 区的左边界-1
    i ← low             // 扫描指针
    
    while i ≤ gt do
        if A[i] < pivot then
            swap(A[lt], A[i])
            lt ← lt + 1
            i ← i + 1
        else if A[i] > pivot then
            swap(A[i], A[gt])
            gt ← gt - 1
            // i 不增加，因为交换来的新元素还未处理
        else
            i ← i + 1   // A[i] = pivot，保留在中间
    
    // 划分结果：
    // A[low..lt-1] < pivot
    // A[lt..gt] = pivot
    // A[gt+1..high] > pivot
    return (lt, gt)     // 返回等于区的起止下标
```

**(d)** 三路快速排序：

```
Algorithm ThreeWayQuickSort(A[1..n], low, high)
    if low < high then
        (q, t) ← ThreeWaySplit(A, low, high)
        // 递归排序 < 区和 > 区，= 区已就位无需处理
        ThreeWayQuickSort(A, low, q - 1)
        ThreeWayQuickSort(A, t + 1, high)
```

**三路快排的优势：**

当所有元素相等时：
- 首次划分后 $lt = low$，$gt = high$，$i$ 从 $low$ 扫描到 $high$，所有元素都被归入等于区
- 递归调用 `ThreeWayQuickSort(A, low, -1)` 和 `ThreeWayQuickSort(A, high+1, high)`，直接返回
- 时间复杂度为 $O(n)$，而非 $O(n^2)$

**通用复杂度：** 平均 $O(n \log n)$，有大量重复元素时性能优于标准快排。

## 六、顶点覆盖问题的 NP 完全性证明（20 分）

**顶点覆盖问题（Vertex Cover）：** 给定无向图 $G = (V, E)$ 和正整数 $k$，问是否存在顶点子集 $U \subseteq V$，$|U| \le k$，使得每条边至少有一个端点在 $U$ 中。

证明顶点覆盖问题是 NP 完全的。

---

**参考答案：**

**证明分两步：**

**Step 1：顶点覆盖 $\in$ NP**

**证书：** 一个顶点子集 $U \subseteq V$。

**验证器：**
```
Certifier(G = (V, E), k, U)
    if |U| > k then return false
    for each (u, v) in E do
        if u ∉ U and v ∉ U then return false
    return true
```

- 证书长度 $|U| \le |V|$，是输入规模的多项式
- 验证器遍历所有边检查覆盖性，$O(|V| + |E|)$ 时间
- 存在证书当且仅当 $G$ 有大小 $\le k$ 的顶点覆盖

故顶点覆盖 $\in$ NP。

**Step 2：顶点覆盖是 NP 难的**

从独立集问题（Independent Set）归约。

**已知：** 独立集问题是 NP 完全的（可从 3-SAT 归约得到）。

**独立集问题：** 给定图 $G = (V, E)$ 和正整数 $k$，问是否存在顶点子集 $I \subseteq V$，$|I| \ge k$，使得 $I$ 中任意两点之间没有边相连。

**归约构造：** 对于任意独立集实例 $(G, k)$，构造顶点覆盖实例 $(G, |V| - k)$。

**正确性证明：** 对于图 $G = (V, E)$ 和顶点子集 $U \subseteq V$，以下两个命题等价：

> $U$ 是顶点覆盖 $\iff$ $V \setminus U$ 是独立集

**证明：**
- ($\Rightarrow$) 若 $U$ 是顶点覆盖，则每条边至少有一个端点在 $U$ 中。因此 $V \setminus U$ 中任意两点之间没有边相连，故 $V \setminus U$ 是独立集。
- ($\Leftarrow$) 若 $I = V \setminus U$ 是独立集，则 $I$ 中任意两点之间无连边，即每条边至少有一个端点不在 $I$ 中、在 $U$ 中，故 $U$ 是顶点覆盖。

因此，$G$ 有大小 $\ge k$ 的独立集 $\iff$ $G$ 有大小 $\le |V| - k$ 的顶点覆盖。

该归约是多项式时间的（$O(1)$ 计算 $|V| - k$）。
