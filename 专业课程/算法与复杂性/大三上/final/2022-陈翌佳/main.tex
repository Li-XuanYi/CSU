\section*{Problem 1. (15 points)}
For every \(n \geqslant 1\) let
\[ \mathcal{H}_n \coloneqq \{S \subseteq \{1, \ldots, n\} \mid |S| = \lceil n / 2 \rceil \}. \]
Prove that
\[ 2^{n / 2} \leqslant |\mathcal{H}_n| \leqslant 2^n. \]
\textbf{Hint:} consider the set \(\{S \mid S \subseteq \{1, \ldots, \lceil n / 2 \rceil \} \}\).

\section*{Problem 2. (10 points)}
Solve the following recurrence relations and give an \(O\) bound for each of them.

\begin{enumerate}[label=(\arabic*), leftmargin=*]
    \item \(T(n) = 4 \cdot T(\lfloor n / 3 \rfloor) + 5 \cdot n.\)
    \item \(T(1) = 1\) and \(T(n) = T(\lfloor \sqrt{n} \rfloor) + 5\) for \(n \geqslant 2\).
\end{enumerate}

\section*{Problem 3. (10 points)}
Show that if an undirected graph with \(n\) vertices has \(k\) connected components, then it has at least \(n - k\) edges.

\section*{Problem 4. (20 points)}
Given two strings \(x = x_1 x_2 \cdots x_n\) and \(y = y_1 y_2 \cdots y_m\), we wish to find the length of their longest common substring, that is, the largest \(k\) for which there are indices \(i\) and \(j\) with \(x_i x_{i+1} \cdots x_{i+k-1} = y_j y_{j+1} \cdots y_{j+k-1}\). Show how to do this in time \(O(m \cdot n)\).

\section*{Problem 6. (15 points)}
Prove that
\[ \sqrt{|V|} \text{-CLIQUE} \]
\textbf{Instance:} A graph \(G = (V, E)\) \\
\textbf{Problem:} Output a clique of size \(\left[ \sqrt{|V|} \right]\) in \(G\) if exists.
is NP-complete.

\section*{Problem 7. (15 points)}
Let \(d \in \mathbb{N}\). The \(d\)-COLORABILITY problem is to decide whether a given graph \(G = (V, E)\) can be colored by \(d\) colors, i.e., whether there exists a function \(f: V \to \{1, \ldots, d\}\) such that for every \(u, v \in V\) with \(\{u, v\} \in E\) we have \(f(u) \neq f(v)\).

\begin{enumerate}[label=(\arabic*), leftmargin=*]
    \item Formulate \(d\)-COLORABILITY as a search problem.
    \item Give a reduction from 4-COLORABILITY to 7-COLORABILITY.
\end{enumerate}
